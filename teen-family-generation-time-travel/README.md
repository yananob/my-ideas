# AI中高生『わが家の「ジェネレーション・タイムトラベル」プロデューサー』 (AI Teen Family "Generation Time-Travel" Producer)

## 概要
中高生が「タイムトラベル・ガイド」となり、親や祖父母が自分と同じ年齢だった頃の社会背景、流行、価値観をAIで再現・比較するアプリです。世代間の「同じ年齢での体験」を並置することで、親を「一人の人間」として捉え直し、時代を超えた深い共感とリスペクトを生む対話をプロデュースします。

## 主な機能
- **コンテクスチュアル・タイムマシン**: 親や祖父母が今の自分と同い年だった年のヒット曲、流行語、当時のニュース、若者の悩みなどをAIがキュレーション。当時の空気感を没入感のあるレポートやプレイリストとして再現します。
- **ジェネレーション・シンクロ・年表**: 家族全員の「15歳の時」を横並びで比較できるビジュアル年表を生成。それぞれの時代の技術、流行、社会状況の違いと、変わらない「若者としての悩み」を可視化します。
- **共鳴ダイアログ・ガイド**: AIが再現した時代背景に基づき、「お父さんが今の僕と同じ年の頃、〇〇が流行ってたみたいだけど、どう思ってた？」といった、当時の感情を引き出す効果的な質問を中高生に提案します。
- **フューチャー・プロジェクション（未来投影）**: 現在のトレンドから、中高生が親の現在の年齢になった時の世界をAIが予測。親子で「未来の同い年」を想像し、世代を超えた長期的な視点を共有します。

## 家族にとってのメリット
- **世代間の壁の解消**: 「親」という役割ではなく、同じ年齢の「一人の若者」として向き合うことで、相互理解とリスペクトが深まります。
- **歴史と文脈の理解**: 家族の歴史を社会の歴史と紐づけて理解することで、自分のルーツに対する誇りや客観的な視点が養われます。
- **共通の会話ネタの創出**: 「昔は良かった」という説教ではなく、AIが提示する客観的なデータに基づいたワクワクする発見を通じて、自然と会話が弾みます。

## ロードマップ
- **v1.0**: 指定した年の流行・ニュースのAI要約生成と、シンプルな比較年表機能。
- **v2.0**: 当時のヒット曲や映像（公開情報）へのリンク統合と、AIによるインタビュー質問自動生成。
- **v3.0**: 家族の写真をアップロードし、当時の流行ファッションをAIで合成して「タイムトラベル写真館」を作る機能や、VR空間での「当時の部屋」再現。
