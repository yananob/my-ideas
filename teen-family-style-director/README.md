# AI中高生『わが家の「スタイル・ディレクター」』 (AI Teen Family Style Director)

## 概要
ファッションや美容に関心が高い中高生が「スタイル・ディレクター」となり、AIの力を借りて家族全員のビジュアル・アイデンティティ（服装、髪型、身だしなみ）をプロデュースするアプリ。親の「最近のトレンドがわからない」「何を着ればいいか迷う」という悩みを解決しながら、家族全員が自信を持って毎日を過ごせるようサポートします。中高生の瑞々しい感性を活かし、家族のコミュニケーションに「おしゃれ」という楽しさを加えます。

## 主な機能
- **AIスタイル診断＆プロファイリング**: 家族の写真をAIが解析し、パーソナルカラー、骨格、顔タイプを客観的に診断。それぞれのメンバーに似合うスタイルを言語化・可視化し、家族独自の「スタイル・ガイドブック」を作成します。
- **スマート・デジタル・クローゼット**: 家族の持ち服をスマホでスキャンして一括管理。中高生のディレクターが「お父さんの手持ちのシャツを今っぽく着こなす方法」や「家族でのディナー向けのリンクコーデ」をAIと一緒に構成・提案します。
- **ジェネレーション・トレンド・キュレーション**: 最新のトレンド情報をAIがフィルタリングし、親の世代でも自然に取り入れられる「大人なトレンド術」として中高生が提案。買い物前に「今買うべきアイテム」をリストアップします。
- **クローゼット・サステナビリティ・コーチ**: 衣服の購入頻度や活用状況をAIが分析。着なくなった服のリサイクルや、フリマアプリへの出品代行（中高生が実施）をサポートし、環境に優しく経済的なファッション・ライフをプロデュースします。

## ロードマップ
- **v1.0**: AIによるスタイル診断機能と、家族の持ち服を登録・共有するデジタルクローゼットの実装。
- **v2.0**: シーンに合わせたコーディネート提案機能（AI生成画像によるイメージ提示）と、トレンド情報の自動要約。
- **v3.0**: 提携ブランドやECサイトとの連携によるバーチャル試着機能、および衣服の二次流通（リセール・リサイクル）の自動管理システム。
