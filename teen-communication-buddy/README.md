# AI中高生『心の通訳』・コミュニケーション・バディ (AI Teen Heart-Translator & Communication Buddy)

## 概要
友人関係、部活動、親子関係など、複雑な人間関係の中で悩み、言葉に詰まることが多い中高生のためのコミュニケーション支援AIエージェントです。自分の本当の気持ちを言語化する手助けをし、相手に伝えるためのメッセージの下書きや、対人トラブルのロールプレイングを通じて、社会性と思考力を育みます。単なる「代行」ではなく、本人が納得感を持って対話に臨めるようサポートします。

## 主な機能
- **「言いたいこと」言語化サポート**: 「なんかモヤモヤする」といった抽象的な感情をAIとの対話で紐解き、何に困っているのか、どうしたいのかを明確にします。
- **スマート・メッセージ・ドラフト**: 友人への謝罪、先生への相談、親への要望など、シチュエーションに応じた適切なメッセージ案を複数提示します。「角が立たない表現」や「自分の気持ちを素直に伝える表現」など、トーンを選べます。
- **安心ロールプレイング**: 緊張する話し合いや面談の前に、AIが相手役になってシミュレーションを行います。想定される反論や質問への返しを練習し、自信を持って本番に臨めます。
- **エモーショナル・リフレーミング**: 相手から言われたショックな言葉や、SNSでの反応をAIが客観的に分析。「相手はこう考えていたのかも」「これは自分のせいではない」といった多角的な視点を提供し、心の回復を助けます。

## ロードマップ
- **v1.0**: テキストベースのメッセージ下書き機能と、感情の言語化サポート機能。
- **v2.0**: 音声対話によるロールプレイング機能と、頻出する悩み別のコミュニケーション・ガイド。
- **v3.0**: 過去の対話データに基づく自己成長レポート機能や、心理学に基づいたアンガーマネジメント・ストレスコーピング支援。
