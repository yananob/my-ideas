# AI中高生『わが家のスタートアップ・メンター』 (AI Teen Family Startup Mentor)

## 概要
柔軟な発想とデジタルツールへの適応力を持つ中高生が「スタートアップ・メンター」となり、家族が抱く小さなアイデアや「こんなことができたらいいな」という願いを、AIと共にビジネスやプロジェクトとして形にするのを支援するアプリ。家族の創造性を引き出し、起業家精神（アントレプレナーシップ）を共に育みます。

## 主な機能
- **アイデア・インキュベーター**: 家族のふとしたアイデアをAIとの対話で深掘りし、リーンキャンバス（ビジネスモデルの骨子）にまとめます。中高生はメンターとして、客観的な視点とAIの分析結果をもとに助言します。
- **AIプロトタイピング・アシスト**: アイデアを可視化するため、ロゴデザイン、ウェブサイトの構成案、または商品のモックアップ画像をAIで即座に生成。形にすることで家族のワクワクを加速させます。
- **ピッチ・トレーニング・バディ**: 家族のプロジェクトを応援してくれる協力者（親戚や友人など）に向けた、魅力的なプレゼン構成をAIと作成。発表の練習を中高生がフィードバックします。
- **わが家の「お仕事」マーケット**: 家族内での小さな困りごと解決や特技の提供を「サービス」として定義。適切な価格設定や価値提供の仕方をAIとシミュレーションし、家庭内での小さな経済循環を体験します。

## ロードマップ
- **v1.0**: アイデア深掘り対話機能と、シンプルなビジネスモデル案の生成。
- **v2.0**: 画像生成AIを活用したビジュアルプロトタイプ作成機能。
- **v3.0**: 外部のクラウドファンディング事例やスモールビジネスの成功パターンを学習した、より高度な戦略提案機能。
