# AI中高生『わが家の「暗黙知」マネージャー』 (AI Teen Family Knowledge Manager)

## 概要
家族の中に眠っている「言語化されていないノウハウ（暗黙知）」を、中高生が「ナレッジエンジニア」となってAIと共に発掘し、家族の共有資産にするアプリです。「おばあちゃんの煮物の火加減」や「父さん独自の庭の手入れ術」など、マニュアル化しにくい「わが家の知恵」を救い出し、家族の絆と生活の質を高めます。

## 主な機能
- **「コツ」発掘インタビュー**: AIが中高生に、家族へのインタビューのコツや質問案を提案。対話を通じて、家族が無意識に行っているこだわりや工夫を引き出します。
- **暗黙知の構造化（ナレッジ・カード）**: インタビュー動画や音声、メモからAIが重要な「コツ」を抽出し、画像や動画を交えた分かりやすいデジタル・ナレッジ・カードとして構造化します。
- **ナレッジ・アシスタント**: 蓄積されたデータに基づき、「おばあちゃんの味を再現するには？」といった質問にAIが回答。中高生がまとめた知恵が、いつでも家族の助けになります。
- **ナレッジ継承チャレンジ**: 構造化したノウハウを他の家族が実践し、その結果をフィードバック。知恵が正しく伝わったかを中高生が確認し、さらにナレッジを磨き上げます。

## 家族にとってのメリット
- **大切な知恵の保存**: 世代を超えて受け継ぎたい「わが家流」の技術や知識を、失われる前にデジタル資産として残せます。
- **中高生のリーダーシップ**: 家族の役に立つ情報を整理・管理する役割を通じて、論理的思考力とコミュニケーション能力を育みます。
- **世代間の深い交流**: インタビューを通じて、家族の歩みや経験に対する深い理解と尊敬の念が生まれます。

## ロードマップ
- **v1.0**: 音声からのノウハウ抽出機能と、シンプルなナレッジベース構築機能。
- **v2.0**: 画像生成AIによる「手順の図解」生成と、マルチメディア対応のカード作成機能。
- **v3.0**: 家族の活動（料理、掃除など）をカメラで見守り、リアルタイムで「わが家のコツ」をアドバイスするAR連携機能。
