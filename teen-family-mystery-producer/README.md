# AI中高生『わが家の謎解き』プロデューサー (AI Teen Family Mystery Producer)

## 概要
家の中や家族の歴史を舞台に、中高生がAIエージェントと協力して「謎解き・脱出ゲーム」をプロデュースするアプリです。退屈になりがちな家での時間を、家族全員が主役のエンターテインメント空間へと変貌させます。中高生はゲームマスターとして、AIと一緒にストーリー構築、謎（ギミック）の作成、ヒントの管理を行い、家族に驚きと感動の体験を提供します。

## 主な機能
- **ホーム・ストーリー・ビルダー**: 「30年前に失われた家宝の行方」や「リビングに仕掛けられた時限爆弾の解除」など、家の中の特定の場所や家族のエピソードを盛り込んだ没入感のあるストーリーをAIが生成します。
- **ギミック・ジェネレーター**: 「冷蔵庫の中にある次の手がかり」「家族しか知らない思い出の数字を使ったパスワード」など、物理的な環境とデジタルな謎を組み合わせた問題をAIが提案します。
- **ゲームマスター・ダッシュボード**: 中高生が進行状況をリアルタイムで把握し、家族が詰まっている時にAIの助けを借りて絶妙なヒントを出すための管理画面です。
- **デジタル・インベントリ**: 家族がスマホを使って家の中にあるQRコードを読み取ったり、手に入れた「アイテム」を管理したりするためのプレイヤー用インターフェースです。

## ロードマップ
- **v1.0**: ストーリーテンプレートと基本的な謎解き問題の生成機能、QRコード連携。
- **v2.0**: 画像認識を活用した「特定のオブジェクトを探す」クエストや、音声AIによるナレーション演出機能。
- **v3.0**: AR（拡張現実）を活用した空間演出と、他の家庭が作った謎解きを共有・体験できるマーケットプレイス機能。
