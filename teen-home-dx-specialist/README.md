# AI中高生『わが家のDX担当』 (AI Teen Home DX Specialist)

## 概要
デジタルネイティブな中高生が「わが家のDX（デジタルトランスフォーメーション）担当」となり、家族の生活にある「不便」や「非効率」をデジタル技術とAIを使って解決することを支援するAIエージェントです。単にデバイスを使うだけでなく、課題発見、ソリューション提案、実装、運用という一連のプロセスを中高生が主導することで、技術的スキルと問題解決能力を養いながら、家族のQOL（生活の質）を向上させます。

## 主な機能
- **ホーム・ペインポイント・オーディター**: AIが中高生と一緒に家の中の「アナログで面倒なこと」を探し出します（例：紙の買い物リスト、散らかった写真、曖昧な家事分担、町内会の連絡など）。
- **DXレシピ・サジェスター**: 発見した課題に対し、Notion、LINE、自動化ツール（Make/Zapier）、共有カレンダー、AIプロンプトなどを活用した具体的な解決策（レシピ）をAIが提案します。
- **実装ハンズオン・ガイド**: 選んだ解決策を実際に形にするためのステップバイステップのガイドを提供。コードの書き方やツールの設定方法をAIが隣で教えます。
- **ファミリー・ベネフィット・ダッシュボード**: 導入したDX施策によって「どれだけ時間が節約されたか」「どれだけ便利になったか」を可視化。家族からの感謝やフィードバックを集め、さらなる改善のモチベーションに繋げます。

## ロードマップ
- **v1.0**: 課題発見の対話機能と、既存ツール（Googleカレンダー、LINE等）を活用した簡単なDXレシピの提供。
- **v2.0**: Notionや自動化ツール（Make等）を用いた、より高度でカスタマイズ性の高いシステムの構築支援。
- **v3.0**: 家族専用のAIエージェント（GPTs等）を自ら作成し、家の中に「AIの力」を組み込むための開発サポート機能。
