# AI中高生『親子のリバース・メンター』 (AI Teen Reverse Mentor)

## 概要
中高生が「先生（メンター）」、親が「生徒（メンティー）」となり、中高生が今熱中していること、最新のトレンド、デジタル技術、あるいは現代的な価値観を親に教えるプロセスをサポートするAIエージェントです。親子の役割をあえて逆転させることで、中高生の自己肯定感と説明能力を高め、親にとっては子どもの世界を深く理解し、自身のアップデートを行う機会を提供します。

## 主な機能
- **授業プロデュース**: 中高生が親に教えたいテーマ（例：最新のSNS用語、推しの魅力、AIツールの使い方など）を、AIと一緒に「授業カリキュラム」として構成します。
- **トレンド解説・翻訳ガイド**: 専門用語やスラングを、親の世代にも分かりやすい言葉に翻訳するヒントをAIが提案します。「これを説明するときは、昭和の〇〇に例えると伝わりやすいよ」といったアドバイスも。
- **「教え上手」リスニング・コーチ**: 授業中に親が「わからない」と言ったとき、AIが中高生に対して、より伝わりやすい説明の仕方をリアルタイムでコーチングします。
- **学びの成果ジャーナル**: 授業のあとの親の感想や、子どもの教え方の成長を記録。親が「今日学んだこと」をテスト形式で振り返る遊び心のある機能も。

## ロードマップ
- **v1.0**: 授業カリキュラムの作成支援機能と、用語の翻訳ガイド。
- **v2.0**: リアルタイムでの教え方アドバイス機能と、親子で共有できるデジタル・ノート機能。
- **v3.0**: 同じテーマで教え合っている他の親子（メンター・メンティー）の成功事例や工夫をシェアできるコミュニティ機能。
