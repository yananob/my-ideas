# AI中高生『わが家の「ライフ・シミュレーター」』 (AI Teen Family Life Simulator)

## 概要
家族の大きな決断や、新しい挑戦、あるいは「もしも」のシナリオをAIでシミュレートし、中高生が「シミュレーション・ディレクター」として家族の未来をガイドするアプリ。移住、リフォーム、新しい習い事、家計の見直しなど、抽象的な「未来の可能性」を具体的なデータとビジュアルで可視化し、家族全員が納得感を持って次の一歩を踏み出すのをサポートします。

## 主な機能
- **「もしも」のシナリオ・エージェント**: 「もし、家族で地方に移住したら？」「もし、太陽光パネルを設置したら？」といった問いに対し、AIがコスト、時間の使い方、QOL（生活の質）の変化を多角的にシミュレートします。
- **ライフスタイル・プロトタイピング**: 「1週間、全員でデジタルデトックスをしたら？」のような新しい生活習慣の導入をシミュレート。予測されるストレス、得られるメリット、成功のためのコツをAIが提示します。
- **合意形成支援ツール**: シミュレーション結果を比較・検討するためのダッシュボードを提供。中高生がファシリテーターとなり、家族それぞれの意見や懸念をAIに入力することで、全員が納得できる「第3の選択肢」を導き出します。
- **バーチャル・プレビュー**: 生成AIを活用し、変化した後の生活（新しい家の内装、移住先の風景、家族の活動の様子など）を画像やストーリー形式でプレビュー。未来を「体験」することで、心理的なハードルを下げます。

## ロードマップ
- **v1.0**: 簡易的なコスト・スケジュールシミュレーションと、AIによるメリット・デメリット分析機能。
- **v2.0**: 外部データ（地価、光熱費統計、教育環境データなど）との連携による、より高精度な地域・家計シミュレーション。
- **v3.0**: 拡張現実（AR）やVRと連携した、より没入感のある「未来生活プレビュー」機能。
