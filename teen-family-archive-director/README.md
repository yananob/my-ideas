# AI中高生『わが家のアーカイブ・ディレクター』 (AI Teen Family Archive Director)

## 概要
スマホに眠る膨大な写真や動画、押し入れの古いアルバム。これらを中高生が「ディレクター」となり、AIの力を借りて家族の貴重な資産（デジタル・ヘリテージ）として整理・再構成するアプリ。家族の歴史を紐解くことで、自分のルーツを確認し、親子の対話を生むきっかけを作ります。

## 主な機能
- **スマート・アーカイブ・スキャン**: AIが写真や動画の内容、表情、位置情報を解析。重要なイベントや「家族らしい瞬間」を自動的にピックアップし、タグ付けします。
- **エピソード・インタビュー・ガイド**: 特定の写真を見せながら親や祖父母に話を聞く際の「深掘り質問」をAIが提案。ボイスメモからエピソードをテキスト化し、写真と紐づけます。
- **メモリアル・ストーリー生成**: 整理した素材を元に、AIが「わが家の歩み」を一本のショートムービーやデジタルマガジンとして自動構成。中高生がエフェクトやナレーションをディレクションします。
- **未来へのタイムカプセル**: 20年後の自分や家族に向けたメッセージを、今の家族の空気感と共に保存。成人式や結婚式など、特定のタイミングで開封されるよう設定できます。

## ロードマップ
- **v1.0**: 写真・動画の自動タグ付けと、シンプルなアルバム作成機能。
- **v2.0**: 音声からのエピソード抽出と、AIによるストーリーテリング（構成案作成）機能。
- **v3.0**: 物理的なアルバムのデジタル化支援（スキャンアドバイス）と、VR/AR空間での「わが家ミュージアム」構築機能。
