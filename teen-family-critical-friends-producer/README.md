# AI中高生『わが家の「クリティカル・フレンズ」プロデューサー』 (AI Teen Family "Critical Friends" Producer)

## 概要
「クリティカル・フレンズ」とは、相手の成長を願って、批判を恐れずに建設的なフィードバックをくれる信頼できる友人のこと。このアプリは、中高生がAIの客観的な分析力を味方につけ、親の仕事、副業、趣味、ライフプランなどに対して、若者ならではの感性と論理的な視点から「良き批判者」としてアドバイスを送るためのプラットフォームです。親の「思考の盲点」を突くことで、家族全体の意思決定の質を高め、互いを一人の自立した個人として尊重し合う関係性を築きます。

## 主な機能
- **フィードバック・ラボ**: 親が作成したプレゼン資料、企画書、あるいは趣味の作品（写真、文章、料理など）をアップロード。AIが論理的整合性や若者への訴求力を分析し、中高生がそれをもとに「ここをこうすればもっと良くなる」というアドバイスを構成します。
- **リバース・インタビュー**: 親の新しい挑戦や悩みに対し、中高生がAIが提案する「鋭い質問」を投げかけます。問いに答える過程で、親自身が自分の考えを整理し、深めることができます。
- **「若者バイアス」チェッカー**: 親の世代では当たり前だと思っている価値観や言葉遣いが、現代の感覚（Z・α世代）から見てどう映るかをAIと判定。「おじさん/おばさん構文」や古いジェンダー観などを優しく指摘します。
- **サンキュー＆アップデート**: 親はもらったフィードバックをどう活かしたかを報告。建設的な批判が成果につながる喜びを共有し、感謝の循環を生みます。

## 家族にとってのメリット
- **親の成長**: 職場では得られない、身近でかつ客観的なフィードバックにより、仕事や趣味の質が向上します。
- **子の自立と自信**: 自分の意見が親の役に立つ経験を通じて、論理的思考力と自己肯定感が育まれます。
- **対等な対話**: 「親と子」という役割を超えて、共通の課題に取り組む「チームメイト」としての絆が深まります。

## ロードマップ
- **v1.0**: シンプルなファイル共有と、AIによる改善案提示、中高生によるコメント機能。
- **v2.0**: 音声入力による「壁打ち対話」サポートと、フィードバックの履歴管理機能。
- **v3.0**: 外部のトレンドデータと連携し、より高度な市場性・社会性分析を含めたプロフェッショナルなアドバイス支援。
