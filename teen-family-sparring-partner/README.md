# AI中高生『わが家の「お悩み解決・壁打ち」パートナー』 (AI Teen Family Problem-Solving Sparring Partner)

## 概要
中高生が「ファシリテーター」となり、AIと協力して、親や兄弟の悩みに対して多角的な視点を提供するアプリ。若者らしい柔軟な感性と、AIの膨大な知識・論理的思考を組み合わせることで、家庭内に新しい解決の風を吹き込みます。中高生は「家族の相談役」としての役割を担い、共感力、論理的思考、転じて客観的な問題解決能力を養います。

## 主な機能
- **世代間感性スパーリング**: 親の仕事や人間関係の悩みに対し、中高生が最新のトレンドや若者の価値観をベースにした意見を提示。AIがそれを論理的に補足し、親にとって「目から鱗」の解決策を提案します。
- **AI多角的視点シミュレーター**: 一つの悩みに対し、AIが「哲学者」「起業家」「コメディアン」など異なるキャラクターになりきって回答を生成。中高生がそれらをキュレーションし、親に最も響く「視点のギフト」として届けます。
- **リフレーミング・ダイアログ**: 家族が抱えるネガティブな捉え方（例：「仕事で失敗した」）に対し、中高生とAIが協力してポジティブな側面や学びのチャンスを見出す（リフレーミング）対話をガイドします。
- **解決の進捗「応援」ログ**: 提案した解決策を家族が試した結果を記録。中高生が「その後どうなった？」と優しくフォローし、AIが次のステップに向けた小さな励まし（ナッジ）を送ります。

## 家族にとってのメリット
- **新しい視点の獲得**: 親が一人では行き詰まってしまう悩みに対し、子どもの感性とAIの知性が新しい突破口を開きます。
- **親子の対等な対話**: 「教える・教えられる」の関係を超え、一人の人間として悩みを共有し、共に解決を目指すことで、深い信頼関係が築かれます。
- **中高生の自信とスキル向上**: 家族の役に立つという実感（自己有用感）と、複雑な問題を整理・解決する高度な思考スキルが身につきます。

## ロードマップ
- **v1.0**: 悩み入力と、AIによる多角的視点（3キャラクター）生成機能。
- **v2.0**: 中高生が意見を付け加えるための「若者言葉・トレンド辞書」連携と、リフレーミング支援機能。
- **v3.0**: 過去の解決事例を蓄積する「わが家の知恵袋」データベース化と、音声対話によるリアルタイム・スパーリング機能。
