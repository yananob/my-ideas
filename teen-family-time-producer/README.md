# AI中高生『わが家の「タイパ」・プロデューサー』 (AI Teen Family "Time Performance" Producer)

## 概要
日々、勉強や部活、趣味に忙しい中高生は、限られた時間をいかに効率的に使うか（タイパ＝タイムパフォーマンス）に敏感です。このアプリは、そんな中高生が「わが家のタイパ担当」となり、AIと協力して家族全体の生活動線やスケジュールを最適化するエージェントです。無駄な待ち時間や家事の重複を減らすことで、家族全員がゆとりを持って、本当にやりたいことに時間を使える「豊かな暮らし」をプロデュースします。

## 主な機能
- **「タイパ」ボトルネック診断**: AIが家族の1日の流れ（朝の準備、夕食の片付け、洗濯など）を対話形式でヒアリング. どこで時間がかかっているか、誰に負担が偏っているかの「ボトルネック」を特定します。
- **スマート・フロー・デザイン**: 診断結果に基づき、家事の分担変更や、動線の改善案（例：「ゴミ出しのルートをこう変える」「朝の洗面所の順番を入れ替える」）をAIがプロデューサー（中高生）と一緒に作成します。
- **時短テク・コネクター**: 「この家事は最新の家電やサブスクで時短できるよ」「このレシピなら15分で終わるよ」といった、タイパ向上のための具体的なソリューションをAIが提案。中高生が家族にプレゼンするのを支援します。
- **「ゆとり時間」クリエーター**: 節約できた時間で何をするか（家族で映画を観る、ゆっくりお茶を飲む、各々の趣味に没頭するなど）をAIがキュレーション。効率化の先にある「心の豊かさ」までをセットでデザインします。

## ロードマップ
- **v1.0**: 家族のスケジュール共有と、簡単な日常動作の効率化アドバイス機能。
- **v2.0**: 生活動線の可視化と、ボトルネック診断に基づく具体的な分担・フロー改善案の生成。
- **v3.0**: 節約された時間の計測と、家族の幸福度を最大化するための「余暇時間」の自動マッチング・プロデュース機能。
