# AI中高生『わが家のナッジ・エンジニア』 (AI Teen Home Nudge Engineer)

## 概要
行動経済学の「ナッジ（そっと後押しすること）」を活用し、家族が無理なく、自発的に良い習慣（片付け、節電、健康的な食事など）を身につけられるよう、住環境や仕組みをデザインする中高生主導のプロジェクトを支援するAIエージェントです。

## 主な機能
- **ナッジ・デザイン・ラボ**: AIが行動経済学の理論に基づき、家族の「ついついやってしまう悪い癖」を「自然とやってしまう良い習慣」に変えるための仕掛けを中高生と一緒に考えます（例：階段に消費カロリーを貼る、野菜を冷蔵庫の手前に置く、スマホ置き場をデザインするなど）。
- **行動ログ・アナリティクス**: センサーやカメラ（または家族の入力）からのデータをAIが分析し、仕掛けの導入前後で家族の行動がどう変わったかを可視化します。
- **エシカル・アーキテクチャ・ガイド**: 「本人の意思を尊重する」というナッジの倫理を守るためのガイドラインをAIが提供。無理強いではなく、みんなが楽しく過ごせるためのデザインを追求します。
- **改善報告ダッシュボード**: 家族がどれだけ健康に、あるいは快適になったかをデータで示し、中高生の貢献を家族にアピールします。

## ロードマップ
- **v1.0**: 日常生活の悩みに基づく基本的なナッジ（仕掛け）の提案機能。
- **v2.0**: IoTデバイスやスマートホーム機器と連携した、より精度の高い行動分析とフィードバック機能。
- **v3.0**: 同じ悩みを持つ他の家庭とナッジのアイデアを共有し、効果を競い合う「わが家の改善コンテスト」機能。
