# AI中高生『わが家の「メンタルモデル」マスター』 (AI Teen Family Mental Model Master)

## 概要
中高生が「メンタルモデル・マスター」となり、世界中の優れた思想家、投資家、科学者、経営者が使っている「思考の枠組み（メンタルモデル）」をAIと一緒に家族へ紹介・適用するアプリです。日々の些細な悩みから家族の重大な決断まで、感情や直感だけに頼らず、複数の論理的な視点からアプローチすることで、家族全体の「思考の質」と「意思決定の精度」をアップデートします。

## 主な機能
- **思考の武器庫（ライブラリ）**: 「第一原理思考」「逆転の発想」「機会費用」「パレートの法則」「ハンロンの剃刀」など、100種類以上の強力なメンタルモデルをAIが中高生に分かりやすく解説。家族の状況に合わせたモデルの選び方をガイドします。
- **ディシジョン・サポート・ラボ**: 家族が直面している課題（例：進路、大きな買い物、旅行先、家事分担）を入力。AIが「もしイーロン・マスクならこう考える」「もしチャーリー・マンガーならこう考える」といった異なるモデルを適用した解決策を提示します。
- **バイアス・ディテクター**: 家族会議中の発言をAIが分析。無意識の偏見（確証バイアス、損失回避、サンクコストの誤謬など）を検知し、中高生が「それはもしかしてバイアスかも？」と優しく指摘するためのヒントを提示します。
- **わが家の意思決定アーカイブ**: 過去の決断とその時の思考プロセスを記録。時間が経ってから「あの時の考えは正しかったか」を振り返り、家族独自の「思考の成功パターン」を蓄積します。

## 家族にとってのメリット
- **意思決定の質の向上**: 感情的な対立を避け、客観的で論理的な根拠に基づいた納得感のある結論を導き出せます。
- **高度なリテラシーの習得**: 中高生が社会に出る前に、世界トップレベルの知識人が共有する思考の枠組みを実生活の中で自然に習得できます。
- **建設的なコミュニケーション**: 互いの意見を否定するのではなく「別のメンタルモデルを適用してみよう」という共通言語を持つことで、議論がクリエイティブになります。

## ロードマップ
- **v1.0**: 主要な30種類のメンタルモデル解説と、シンプルな意思決定支援チャット機能。
- **v2.0**: 音声入力からのバイアス検知機能と、思考プロセスを図解化するビジュアライザーの実装。
- **v3.0**: 家族それぞれの思考の癖をAIが分析し、パーソナライズされた「思考のトレーニング」を提案する機能。
