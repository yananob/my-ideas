# AI中高生『わが家の「ボードゲーム・マスター」』 (AI Teen Family Board Game Master)

## 概要
デジタル画面から離れ、家族が顔を合わせて熱中できる「アナログゲーム（ボードゲーム・カードゲーム）」を、中高生がマスターとしてプロデュースするアプリ。AIが世界中の膨大なゲームデータベースから、わが家の人数、年齢層、今の気分にぴったりのゲームをセレクト。中高生はゲームの選定、ルール解説、場を盛り上げる演出を担当し、家族の対話と笑顔を創出します。

## 主な機能
- **ファミリー・ゲーム・マッチメーカー**: 「今日は短時間で笑いたい」「じっくり戦略を練りたい」「親子の知識差がないゲームがいい」といったリクエストに応じ、AIが最適なアナログゲームを提案。持っているゲームだけでなく、新しく購入・レンタルする際のアドバイスも行います。
- **AIルール・チューター**: 複雑な説明書を読む代わりに、AIが中高生マスターにルールの要点をレクチャー。中高生は「初心者にもわかりやすいインスト（導入説明）」をAIと一緒に練習し、家族をスムーズにゲームの世界へ引き込みます。
- **マスターズ・演出・コンソール**: ゲーム中の雰囲気をAIがサポート。選んだゲームのテーマに合わせたBGMの再生、得点計算の補助、ドラマチックなタイマー機能などで、リビングを本格的なゲーム空間に変貌させます。
- **わが家の戦歴アーカイブ**: 対戦結果や「あの時の大逆転」といった思い出をAIが記録。家族内ランキングや、プレイ中のベストショットをまとめた「対戦日誌」を自動生成し、次のゲームナイトへの期待を高めます。

## ロードマップ
- **v1.0**: 家族の好みに合わせたゲーム推薦機能と、シンプルなインスト（説明）支援ツール。
- **v2.0**: BGM連携機能と、スマホをコントローラーや得点板として使う補助ツールの提供。
- **v3.0**: AIが「ゲームの実況者」として参加し、プレイを盛り上げたり、勝敗の要因を分析して「次回の対策」をアドバイスする高度な演出機能。
