# AI中高生『わが家の「メンタルロード」マネージャー』 (AI Teen Family Mental Load Manager)

## 概要
家事そのものだけでなく、「献立を考える」「備蓄を確認する」「学校の行事を把握する」といった、家庭を運営するための「見えない思考の負担（メンタルロード）」を、中高生がAIと共に可視化し、家族で分担・最適化するアプリ。特定の誰か（主に母親や父親）に偏りがちな心理的・認知的負荷を解き放ち、家族全員が「自分ごと」として家庭を運営する、持続可能でフェアなチーム作りを中高生がリードします。

## 主な機能
- **メンタルロード・マッピング**: AIが家族一人ひとりにインタビューを行い、「名もなき家事」や「常に気にかけていること」を洗い出します。本人が意識していなかった「隠れた負担」をAIが言語化し、構造化します。
- **認知負荷ヒートマップ**: 誰が、いつ、どれだけの「思考の重み」を背負っているかを視覚化。物理的な作業時間だけでなく、「判断の多さ」や「責任の重さ」をスコア化して共有します。
- **思考の「バトンタッチ」プロポーザル**: 負担が偏っている項目に対し、AIが具体的な分担案を提示。「この管理は中高生の僕がやるよ」「この判断はAIとパパで自動化しよう」といった、思考の移譲をサポートします。
- **リスペクト＆感謝エンジン**: AIが「見えない貢献」を自動的に抽出し、家族に通知。「いつも冷蔵庫の中身を把握してくれてありがとう」といった、具体的な感謝を伝えるきっかけを作ります。

## 家族にとってのメリット
- **特定の親のバーンアウト防止**: メンタルロードが共有されることで、心理的な余裕が生まれ、家庭内の雰囲気が明るくなります。
- **中高生のマネジメント能力向上**: 複雑なシステム（家庭）を理解し、課題を解決する力が養われます。
- **家族の絆（レジリエンス）強化**: 互いの苦労を理解し、助け合う「ワンチーム」としての意識が深まります。

## ロードマップ
- **v1.0**: AIインタビューによるメンタルロードの抽出と言語化、リスト表示機能。
- **v2.0**: 負担の可視化（ヒートマップ）と、家族間での簡単な分担（思考の移譲）支援機能。
- **v3.0**: AIエージェントが「思考」の一部を代行（在庫自動発注、スケジュール調整等）し、家族全員の認知負荷を物理的に削減する高度な連携。
