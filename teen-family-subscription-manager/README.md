# AI中高生『わが家の「サブスク」・マネージャー』 (AI Teen Family Subscription Manager)

## 概要
デジタルサービスに親しみのある中高生が「わが家のサブスクリプション（定額制サービス）担当」となり、家族が契約している多様なサービス（動画、音楽、アプリ、クラウド、生活サービス等）をAIと共に賢く管理・最適化するエージェントです。無駄な支出を抑えるだけでなく、契約しているサービスを家族全員で最大限に使いこなし、生活をより楽しく豊かにすることを目的とします。

## 主な機能
- **サブスク・棚卸しバディ**: AIがメールの領収書や利用明細から契約中のサブスクを自動でリストアップ。重複しているサービスや、最近使っていない「幽霊サブスク」を中高生が見つけ出すのをサポートします。
- **バリュー最大化ガイド**: すでに契約しているサービスの「意外と知らない特典」をAIが提案（例：「このサブスクには雑誌読み放題も付いてるよ！」）。家族全員がその価値を使い切れるようガイドします。
- **コスト最適化シミュレーター**: 「家族プランへの切り替え」や「年払いへの変更」による節約効果をAIが算出。中高生が「こうすれば月〇〇円浮くよ」と家族に改善案をプレゼンするのを支援します。
- **わが家の推し活・シェアリング**: 契約中のサービスから、家族の好みに合わせたコンテンツ（映画、音楽、イベント等）をAIがキュレーション。中高生が「今週末はみんなでこれを観よう」と家族の団らんをプロデュースします。

## ロードマップ
- **v1.0**: サブスク一覧の作成と、支払い期日・金額の可視化機能。
- **v2.0**: 利用状況の分析と、未利用サービスや重複の通知、プラン最適化の提案機能。
- **v3.0**: 家族の好みに基づくコンテンツ・キュレーションと、解約・新規契約のシミュレーション機能。
