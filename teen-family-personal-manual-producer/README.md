# AI中高生『わが家の「パーソナル・マニュアル（トリセツ）」プロデューサー』 (AI Teen Family "Personal Manual" Producer)

## 概要
中高生が「プロデューサー」となり、家族一人ひとりの「自分らしい心地よさ」や「人との接し方の好み」をAIと協力して言語化し、わが家専用の『パーソナル・マニュアル（取扱説明書）』を作成するアプリ。思春期特有の「放っておいてほしいけど助けてほしい」といった複雑な心理や、親が気づかない「地雷」を、AIの客観的な表現力を借りて共有することで、不要な衝突を減らし、互いの個性を尊重し合える関係を築きます。

## 主な機能
- **「自分のトリセツ」作成インタビュー**: AIが中高生や親にインタビュー。「集中している時に話しかけられたら？」「落ち込んでいる時の理想の対応は？」といった問いへの答えを、角が立たない、かつ的確な「取扱説明」にAIが変換します。
- **コンディション・アップデート**: 「今日はテストの結果が悪かったので、そっとしておいてモード（レベル3）」のように、その日の「取扱時の注意点」をリアルタイムで家族に通知。AIが「今はこういう言葉をかけるのがベスト」とアドバイスします。
- **家族の「地雷」マップ**: 家族それぞれの「これを言われるとやる気がなくなる」という言葉や行動を可視化。AIが「その代わりになるポジティブなアプローチ」を提案します。
- **相互理解クイズ**: 作成されたマニュアルを元に、家族でクイズを実施。楽しみながら互いの特性や境界線（バウンダリー）を学び合います。

## 家族にとってのメリット
- **無用な衝突の回避**: 相手の「地雷」や「今の状態」を事前に知ることで、感情的な対立を未然に防げます。
- **心理的安全性の向上**: 自分の特性を家族が理解し、尊重してくれているという安心感が生まれます。
- **中高生の言語化能力**: 自分の感情やニーズを客観的に捉え、他者に伝えるためのコミュニケーションスキルが養われます。

## ロードマップ
- **v1.0**: AIインタビューによる基本的なマニュアル作成機能と、PDF/画像出力。
- **v2.0**: その日の気分や状態を共有する「コンディション・バッジ」機能と、AIによる声かけアドバイス。
- **v3.0**: 家族の対話ログから「地雷」を自動検出し、マニュアルを自動更新する高度なメンテンナンス機能。
