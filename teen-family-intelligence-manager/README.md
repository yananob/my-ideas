# AI中高生『わが家の「インテリジェンス・マネージャー」』 (AI Teen Family Intelligence Manager)

## 概要
デジタルネイティブな中高生が、AIを相棒に「わが家の知性」をアップデートするリーダー。日々の生活に必要な情報管理から、家族の教養を深める知識のキュレーションまでをプロデュースし、家族全員の知的生命力を高めます。

## 主な機能
- **ファミリー・ナレッジ・ベース**: 家電の保証書、契約書類、家族のパスポートのコピー、はたまた「わが家秘伝の裏技」まで、あらゆる「知恵と情報」をスキャン・構造化して整理。必要な時にAIがすぐ答えてくれます。
- **ディナータイム・キュレーション**: 家族の関心事や社会の動向から、その日の夕食で語り合いたくなるような「深掘りテーマ」をAIと選定。ただのニュースではなく、背景知識や異なる視点もセットで提供し、知的な会話をファシリテートします。
- **わが家の「学び」コンシェルジュ**: 家族それぞれの目標（資格、趣味、進路）に合わせて、AIが最適な学習リソースや最新情報をキュレーション。中高生がそれぞれの成長を応援する情報の橋渡し役を担います。
- **情報セキュリティ・アドバイザー**: 家族が受け取った不審なメールや、最新の詐欺・デマ情報への対策をAIとチェック。家族の「情報の安全」を守る知的なガードマンとしての役割。

## ロードマップ
- **v1.0**: 書類整理機能（OCRと要約）と、日替わりの会話テーマ提案機能。
- **v2.0**: 家族それぞれの興味プロファイル構築と、パーソナライズされたニュース・記事の推奨。
- **v3.0**: 外部の専門データベースや学習プラットフォームと連携し、より高度な「家庭内シンクタンク」としての機能を実現。
