# AI中高生『家族会議』サポーター (AI Teen Family Meeting Supporter)

## 概要
中高生が成長するにつれ、スマホの利用ルールや門限、家事の分担など、家族間で「交渉」が必要な場面が増えてきます。このアプリは、家族間の対話を「勝ち負け」ではなく「共感と論理」に基づく建設的なプロセスへと変え、お互いが納得できる Win-Win な合意形成をAIが支援。中高生の自律性と、家族の深い信頼関係の両立を目指すエージェントです。

## 主な機能
- **トーン＆共感アナライザー**: 会話の感情的なトーンをAIが分析。怒りや不満が爆発する前に、より建設的で共感的な言い換えを提案し、冷静な話し合いをサポートします。
- **視点スイッチ・シミュレーター**: 本番の会議前に、AIが相手（親または子）の立場になりきってロールプレイ。相手の懸念や背景にある想いを体験することで、共感に基づいた歩み寄りを促します。
- **AI「Win-Win」プロポーザル**: 双方の主張を分析し、隠れた共通の目的を発見。お互いの「譲れないポイント」を尊重しつつ、創造的な妥協点（第3の案）をAIが提示します。
- **スマート合意トラッカー＆ナッジ**: 決まったルールを記録し、実行を優しくリマインド。親が口うるさく言う代わりに、AIが「ナッジ（小さな促し）」を行うことで、自発的なルール遵守と良好な関係維持をサポートします。

## ロードマップ
- **v1.0**: 論点整理と「トーン・アナライザー」による対話支援。
- **v2.0**: 視点スイッチ（ロールプレイ）とWin-Win提案エンジンの実装。
- **v3.0**: リアルタイム会議ファシリテーションと、自律運用を支えるスマート・ナッジ・システム。
