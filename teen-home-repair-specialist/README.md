# AI中高生『わが家の「リペア＆アップサイクル」スペシャリスト』 (AI Teen Home Repair & Upcycling Specialist)

## 概要
モノを大切にする心と、DIYや修理のスキルをAIでサポートし、中高生が「わが家のモノの寿命を延ばす責任者」として活躍するためのアプリです。壊れた家電、破れた服、古くなった家具などを、AIの診断とガイドによって修理（リペア）したり、新しい価値を持つモノへと作り替え（アップサイクル）たりすることを支援します。使い捨ての文化から脱却し、家族でサステナブルな暮らしを楽しみながら、中高生のエンジニアリング・マインドと創造性を育みます。

## 主な機能
- **リペア・ダイアグノシス（修理診断）**: 壊れた箇所をカメラで写すと、AIが故障原因を推測し、修理の難易度や必要な道具、手順を提示します。初心者が手を出しにくい「直し方」の第一歩をサポートします。
- **アップサイクル・クリエイター**: 古くなったけど捨てられないモノ（思い出の服、古い家具など）をスキャンすると、AIが現代のライフスタイルに合った新しい用途やリメイク案を提案します。
- **デジタル・メンテナンス・ログ**: 家の中のモノの購入日やメンテナンス履歴を管理。AIが適切なタイミングで「そろそろお手入れの時期だよ」と通知し、モノを長持ちさせる習慣を作ります。
- **わが家の「直し屋」ポートフォリオ**: 修理やアップサイクルしたモノをビフォー・アフターの写真と共に記録。家族からの「ありがとう」コメントも保存し、中高生の貢献を可視化します。

## ロードマップ
- **v1.0**: 画像認識による簡単な修理方法（穴の補修、ネジの緩みなど）の提案と、アップサイクル案のカタログ表示。
- **v2.0**: YouTube等の修理動画から最適な手順をAIが要約・解説する機能と、必要なパーツをECサイトから探す支援機能。
- **v3.0**: 3Dプリンター用の補修パーツデータの生成支援や、地域の「修理の達人」とオンラインで相談できるマッチング機能の検討。
