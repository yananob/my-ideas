# AI中高生『わが家の「知の交差点（コネクティング・ドッツ）」プロデューサー』 (AI Teen Family "Connecting the Dots" Producer)

## 概要
家族一人ひとりが持っているバラバラな興味関心、知識、最近学んだこと（＝点）をAIが収集・分析し、それらを意外な形で繋ぎ合わせることで、新しい家族の「共創プロジェクト」や「深い対話」を中高生がデザインするアプリ。中高生が「プロデューサー」となり、家族の知的資源を最大化し、わが家独自の「知の化学反応」をプロデュースします。

## 主な機能
- **興味の「点」マッピング**: 家族が最近読んだ本、観た動画、気になっているニュースなどをAIがヒアリングし、それぞれの「関心の地図」を作成。本人も気づいていない深層の興味を抽出します。
- **AI「交差点」発見エンジン**: 「お父さんの釣りへのこだわり」と「娘の幾何学への興味」が「流体力学」で繋がる、といった意外な共通項（交差点）をAIが発見し、中高生に通知します。
- **「点と点」を繋ぐプロジェクト提案**: 発見された交差点をもとに、中高生が家族で行う体験プロジェクトを企画（例：「流体力学を応用した最強のルアー自作＆実験キャンプ」）。AIが企画書の作成をサポートします。
- **知的シナジー・レポート**: 興味の繋がりが家族の対話をどう変えたか、新しく得られた視点は何かをAIがまとめ、「わが家の知の成長記録」として可視化します。

## 家族にとってのメリット
- **相互理解の深化**: 家族の活動の背景にある「知的関心」を理解することで、表面的な会話を超えた深い尊敬と共感が生まれます。
- **創造性の刺激**: 異なる領域の知識が結びつく（新結合）体験を家庭内で日常化することで、家族全員のクリエイティブな思考力が養われます。
- **中高生のリーダーシップ**: 家族の知識を統合し、価値を創出する「プロデューサー」としての役割を担うことで、高度な抽象思考力とプロジェクト管理能力が育まれます。

## ロードマップ
- **v1.0**: 家族の興味データの収集と、シンプルな「共通キーワード」の抽出機能。
- **v2.0**: AIによる高度なセマンティック分析を用いた「意外な交差点」の発見とプロジェクト提案機能。
- **v3.0**: 地域のワークショップやオンライン教材等、外部の学びのリソースと交差点を自動的にマッチングする機能。
