# AI中高生『わが家の「生きがい」ナビゲーター』 (AI Teen Family "Ikigai" Navigator)

## 概要
家族一人ひとりが「好きなこと（Passion）」「得意なこと（Mission）」「世界が必要としていること（Vocation）」「収入に繋がること（Profession）」の重なり、すなわち「生きがい（Ikigai）」を見つけることを、中高生がAIと共にナビゲートするアプリ。家族がお互いの人生の目的や情熱を深く理解し、単なる同居人を超えた「人生の共創パートナー」として支え合う文化を育みます。

## 主な機能
- **生きがいチャート・ビルダー**: 日本発の概念「Ikigai」に基づき、AIとの対話を通じて家族それぞれの4つの要素を可視化します。中高生はインタビューアとなり、AIが回答を整理して美しいレーダーチャートを生成します。
- **情熱の「越境」マッチング**: 「お父さんのプログラミングスキル（得意）」で「妹の動物愛護活動（好き）」をどう助けられるか？といった、家族間のスキルと情熱を掛け合わせた新しい共同プロジェクトをAIが提案します。
- **ライフステージ・ピボット・シミュレーター**: 進学、転職、定年退職などの人生の転機において、「生きがい」の観点からどのような選択肢があるかをシミュレーション。中高生の柔軟な発想とAIのデータ分析で、家族の新しい門出を応援します。
- **「生きがい」マイクロ・ナッジ**: 家族のチャートに基づき、日々の生活の中で「生きがい」を感じるための小さなアクション（例：好きな料理を披露する、専門知識を共有するなど）をAIが適切なタイミングで提案します。

## 家族にとってのメリット
- **深い相互理解と尊敬**: 家族の意外な才能や情熱を知ることで、互いに対する尊敬の念が深まり、日常の会話がより本質的で前向きなものになります。
- **家族全体の自己肯定感の向上**: 自分の情熱が家族の役に立っているという実感（自己有用感）が得られ、家庭が個人の成長を最も応援してくれる安全な場所になります。
- **世代を超えたキャリア観の共有**: 親の仕事観や子どもの未来への展望を「生きがい」という共通言語で語り合うことで、健全なキャリア意識が育まれます。

## ロードマップ
- **v1.0**: AI対話による生きがいチャート作成機能と、基本的なプロフィール共有。
- **v2.0**: 家族間のスキル・情熱マッチング機能と、共同プロジェクト提案エンジンの搭載。
- **v3.0**: 過去の活動データに基づく「生きがい成長レポート」の発行と、スマートホーム連携による「集中・情熱タイム」の空間演出機能。
