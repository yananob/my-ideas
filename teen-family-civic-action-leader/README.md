# AI中高生『わが家の「シビック・アクション」リーダー』 (AI Teen Family Civic Action Leader)

## 概要
現代社会の課題について、行政や自治体が意見を募る「パブリックコメント」や「住民対話」の場に、中高生がリーダーとなって家族で参画することをAIがサポートするアプリ。難解な公文書を解きほぐし、家族それぞれの生活実感に基づいた「市民としての意見」を形にすることで、自分たちの手で社会をより良くしていく体験を提供します。

## 主な機能
- **公文書デコーダー (Policy Decoder)**: 国や自治体が出している複雑な政策案や計画書を、AIが中高生にも家族にも分かりやすく要約・解説。自分たちの生活にどう影響するかを明確にします。
- **家族意見ファシリテーター (Family Opinion Facilitator)**: 特定の政策テーマについて、AIが家族の対話をガイド。「賛成・反対」だけでなく、「自分たちはこうなってほしい」という多様な意見を引き出します。
- **シビック・ライティング・バディ (Civic Writing Buddy)**: 家族で話し合った内容を、論理的かつ建設的な「パブリックコメント」や「要望書」としてAIがドラフト。中高生が最終的な推敲を行い、社会に発信します。
- **アクション・インパクト・トラッカー (Action Impact Tracker)**: 自分たちが送った意見がどのように反映されたか、あるいはその後の政策の動きをAIが追跡。自分たちの声が社会に届くプロセスを学びます。

## 家族にとってのメリット
- **主権者教育の実践**: 中高生が「社会の構成員」としての自覚を持ち、論理的思考や文章力を養う最高の機会になります。
- **家族の対話の深化**: ニュースや政治を「遠い世界の話」ではなく、自分たちの生活に繋がる自分事として語り合えます。
- **社会を変える実感**: 小さな一歩が実際の政策に影響を与えるかもしれないという「自己効力感」を家族で共有できます。

## ロードマップ
- **v1.0**: 地域や国のパブリックコメント情報の自動収集と、公文書の要約機能。
- **v2.0**: 家族内での対話ガイドと、論理的な意見書ドラフト生成機能。
- **v3.0**: 同様の関心を持つ他の家庭の意見（匿名）の傾向分析や、実際の採択・反映状況の通知・分析機能。
