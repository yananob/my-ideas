# AI中高生『わが家の「バイアス」監査官』 (AI Teen Family Bias Auditor)

## 概要
家族が何かを決めるとき（大きな買い物、旅行先、進路、あるいは日常の些細な諍い）、知らず知らずのうちに陥っている「思い込み（認知バイアス）」を、中高生が「監査官」となってAIと共に指摘・修正するアプリ。客観的な視点を取り入れることで、感情的な対立を防ぎ、家族全員が納得できる「賢い意思決定」を支えます。

## 主な機能
- **バイアス・ディテクター**: 家族の会話ログや計画書をAIが分析。「確証バイアス（自分の意見に都合の良い情報だけ集める）」「サンクコストバイアス（もったいない精神で損を続ける）」などの兆候を検知し、中高生に通知します。
- **「デビルズ・アドボケイト（あえて反論）」モード**: 家族全員の意見が一致したときこそ、AIが「あえて反対の視点」を提示。中高生がその反論をファシリテートし、多角的な検討を促します。
- **意思決定ジャーナル**: 家族の大きな決断のプロセスを記録。後で振り返り、「あの時の判断は正しかったか？」「どんなバイアスがあったか？」を分析し、家族の「思考の質」を向上させます。
- **ロジカル・シンキング・トレーニング**: ニュースや広告を題材に、AIがクイズ形式でバイアスを見抜く練習を提供。中高生が講師役となり、家族全員のクリティカル・シンキング能力を高めます。

## 家族にとってのメリット
- **納得感のある決断**: 「なんとなく」や「声の大きい人の意見」ではなく、論理的な裏付けを持って決めることができます。
- **知的交流の活性化**: 思考のクセを指摘し合うことが、家族間の楽しい知的エンターテインメントになります。
- **将来に役立つスキル**: 中高生自身が、実生活の中で高度な論理的思考力とファシリテーション能力を身につけることができます。

## ロードマップ
- **v1.0**: 会話テキストからの簡易バイアス診断機能と、代表的な20種類のバイアス解説図鑑。
- **v2.0**: 意思決定プロセスの記録・振り返り機能と、AIによる「反論シミュレーション」。
- **v3.0**: 音声対話中のリアルタイム・バイアス検知と、専門的な意思決定フレームワークとの連携機能。
