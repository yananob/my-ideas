# AI中高生『わが家の空間プロデューサー』 (AI Teen Space Producer)

## 概要
中高生が「わが家の空間プロデューサー」となり、AIとスマートホーム技術を駆使して、家族の生活シーンに最適な「居心地」をデザイン・管理するAIエージェントです。照明、音響、香り、温度などを統合的にコントロールし、家族一人ひとりのウェルビーイングを向上させる空間演出を中高生が主導します。

## 主な機能
- **シーン別「Vibe」デザイン**: 集中したい勉強時間、リラックスしたい夕食後、質の高い睡眠のための入眠準備など、シーンに合わせた光と音の演出プランをAIと一緒に作成します。
- **環境・バイタル連動アドバイザー**: 室温、二酸化炭素濃度、さらには家族の活動ログ（バイタルデータ）と連動し、「今は少し換気して、明るい光に変えた方が効率が上がるよ」といったアドバイスをAIが行います。
- **ホーム・コンフォート・アナリティクス**: どの部屋がいつ、どのように使われ、家族がどれだけ「快適」と感じているかを可視化。改善案を中高生が家族にプレゼンするためのデータをまとめます。
- **「空間の処方箋」ライブラリ**: 季節や天候、家族の気分に合わせた、世界中の「居心地の良い空間」のレシピ（設定値）をAIが提案。わが家独自の「お気に入り設定」を蓄積していきます。

## ロードマップ
- **v1.0**: 照明（スマートライト）と音響の基本プリセット作成機能と、シーン別の手動切り替えサポート。
- **v2.0**: 各種環境センサー（温度、湿度、CO2）との連携による自動アドバイス機能と、快適指数の可視化。
- **v3.0**: 家族の表情や声のトーンから感情を推測し、リアルタイムで空間演出を微調整する「エモーショナル・ライティング」機能の実装。
