# AI中高生『わが家の「関係性リデザイン」プロデューサー』 (AI Teen Family Relationship Redesigner)

## 概要
親子のコミュニケーションを「構造的」にアップデートし、互いに心地よい距離感をデザインするアプリ。中高生が「プロデューサー」となり、AIの客観的な視点と言語化能力を借りて、日常の些細な衝突や言葉にできないモヤモヤを建設的な対話へと変えます。単なる仲介役ではなく、自分の要望を論理的に伝える「交渉力」を養い、家族というチームを自らデザインしていく体験を提供します。

## 主な機能
- **「本音」翻訳・交渉エンジン**: 「ウザい」「ほっといて」といった感情的な反応を、AIが「今は一人で集中したいので、1時間後に話しかけてほしい」といった建設的な要望に翻訳。親に伝えるための最適な「スクリプト（台本）」を生成します。
- **親子バウンダリー（境界線）契約**: 「部屋への入り方」「SNSの干渉度」「成績の話題の出し方」など、互いのデリケートな領域をAI立ち会いのもとで定義。明文化された「契約」として合意形成をサポートします。
- **ペアレント・インサイト分析**: 親の反応パターン（機嫌の良い時間帯、納得しやすい論理構成など）をAIと分析。どう伝えれば自分の要望が通りやすいか、戦略的な交渉術を学びます。
- **感謝のスニペット生成**: 直接言うのは照れくさい「ありがとう」や「ごめん」を、相手の性格に合わせて自然に受け取れる形（メモ、メッセージ、行動など）で提案。関係性の「貯金」を増やします。

## 家族にとってのメリット
- **感情的な衝突の激減**: AIが感情のバッファ（緩衝材）となることで、売り言葉に買い言葉のような不毛な争いを防げます。
- **自律的なコミュニケーションスキルの習得**: 自分のニーズを言語化し、他者と合意を形成する社会人基礎力が家庭内で身につきます。
- **心理的安全性の確保**: 自分の境界線が尊重されることで、家族の間で安心して自己表現ができるようになります。

## ロードマップ
- **v1.0**: AIによるメッセージ翻訳と、交渉スクリプト生成機能の提供。
- **v2.0**: インタラクティブなバウンダリー契約作成ツールと、家族間の「契約書」共有機能。
- **v3.0**: 親子の対話ログに基づく「関係性スコア」の可視化と、長期的な信頼関係構築のためのパーソナライズ・コーチング。
