# AI中高生『わが家の「好奇心スカウター」』プロデューサー (AI Teen Family Curiosity Scouter)

## 概要
中高生が家族の「隠れた興味」や「まだ見ぬ才能」をAIで発掘し、家族全員を未体験の知的・創造的活動へと導くナビゲーターになるアプリ。親が日々の忙しさで忘れてしまったかつての趣味や、日常の会話に潜む小さな好奇心の芽をAIが分析。中高生は「プロデューサー」として、その芽を大きく育てるための「知の越境体験」を家族に提案します。

## 主な機能
- **好奇心シグナル・トラッカー**: 家族の日常会話、SNSのシェア、読んでいる本、視聴した動画などの傾向をAIが分析。本人が無意識に抱いている興味の兆し（シグナル）をキャッチします。
- **好奇心マップ生成**: 家族それぞれの興味関心を可視化し、それらがどう繋がっているか、あるいはどの方向に「越境」できそうかを地図状に表示します。
- **越境体験プロデュース**: AIが「今のパパにはこの最新技術が刺さるはず」「ママの料理好きを活かして、この異文化体験をしよう」といった具体的なアクティビティを提案。中高生がそれらを組み合わせ、週末の「好奇心ツアー」を企画します。
- **未知との遭遇（セレンディピティ）エンジン**: 家族の現在の興味とはあえて少し遠い、しかし確実に刺激を受けるであろう「未知のジャンル」をAIがレコメンド。家族全員で初体験を楽しむきっかけを作ります。

## 家族にとってのメリット
- **親の再発見**: 忙しい日常で埋もれていた親の個性や情熱を、中高生がAIを通じて再発見・再評価する機会になります。
- **対等な知的刺激**: 中高生が「最新の知」や「新しい視点」を親に提供することで、親子という枠を超えた、知的な探究パートナーとしての関係が築けます。
- **家庭のマンネリ解消**: AIが提案する「意外な体験」を家族で共有することで、会話が活性化し、家庭の空気が新しくなります。

## ロードマップ
- **v1.0**: 家族の会話や行動ログからキーワードを抽出する「好奇心キーワード抽出」機能。
- **v2.0**: 好奇心マップの可視化と、中高生向けの「プロデュース・テンプレート」の提供。
- **v3.0**: 外部のイベントや体験プログラムとの自動連携機能。
