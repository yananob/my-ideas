# AI中高生『わが家の「ベネフィット・マネージャー」』 (AI Teen Family Benefit Manager)

## 概要
世の中には多くの公的・民間の支援制度（補助金、助成金、給付金、奨学金、減税措置など）がありますが、その存在を知らなかったり、手続きが複雑で諦めてしまったりすることが少なくありません。このアプリは、情報収集能力の高い中高生が「ベネフィット・マネージャー」となり、AIの力を借りて家族が享受できる「正当な権利と利益」を最大化するサポーターです。

## 主な機能
- **わが家専用ベネフィット・スキャナー**: 家族の構成、居住地、所有資産（家・車など）、ライフイベント（進学、リフォーム、介護など）に基づき、AIが国や自治体、民間企業が提供する利用可能な制度を網羅的にリストアップします。
- **申請サポート・チャット**: 複雑な申請書類や要件をAIが噛み砕いて解説。中高生が「この書類を準備してね」と親をリードし、AIと一緒に下書きを作成したり、チェックリストで進捗を管理したりします。
- **ライフステージ・ウォッチ**: 家族の年齢や状況の変化をAIが先回りして検知。「来年は教育無償化の対象になるよ」「この住宅補助金の期限が近いよ」といった未来のベネフィットを中高生がプレゼンします。
- **奨学金・チャレンジ・ガイド**: 様々な種類の奨学金やコンテストの助成金情報をキュレーション。中高生自身の進路や、家族の学びを経済的に支援するチャンスをAIと発掘します。

## ロードマップ
- **v1.0**: 居住地域と家族構成に基づく主要な公的給付金・助成金の検索・通知機能。
- **v2.0**: ライフイベント（進学・リフォーム等）に特化した詳細なベネフィット・プランニング機能。
- **v3.0**: AIによる申請書類の作成支援（ドラフト生成）と、地域の窓口や専門家への相談サポート機能。
