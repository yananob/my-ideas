# AI中高生『家族プロジェクト・プロデューサー』 (AI Teen Family Project Producer)

## 概要
中高生が「プロデューサー」となり、家族を巻き込んで一つの大きな目標（旅行の計画、家のDIY、季節のイベント開催など）を達成することをサポートするAIエージェントです。親に「やってもらう」立場から、自ら「企画し、人を動かす」立場への成長を促し、社会で役立つプロジェクトマネジメント能力とリーダーシップを家族というチームの中で育みます。

## 主な機能
- **プロジェクト立案・ブレスト**: 「今度の連休でどこか行きたい」「リビングを模様替えしたい」といった断片的なアイデアを、AIとの対話で具体的な「プロジェクト計画」に落とし込みます。
- **プレゼン・ピッチ支援**: 家族（特にスポンサーである親）に企画を承認してもらうための、論理的で魅力的なプレゼン資料の構成や、反対された時の切り返し方をアドバイスします。
- **ロール分配・タスク管理**: 家族メンバーの得意不得意に合わせて、「カメラ担当：お父さん」「予算管理：お母さん」のように役割を振り分け、進捗を可視化します。
- **プロジェクト・アーカイブ**: プロジェクト完了後、写真や支出、感想をまとめて「活動報告書」を自動生成。家族の成功体験を資産として残します。

## ロードマップ
- **v1.0**: 企画立案の対話サポートと、シンプルなタスクリスト生成機能。
- **v2.0**: 親を説得するための「プレゼン資料（スライド構成案）」作成支援と、予算シミュレーター。
- **v3.0**: 外部サービス（宿泊予約、ECサイトなど）との連携による実行支援と、家族からの「プロデューサー評価」フィードバック機能。
