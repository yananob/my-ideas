# AI中高生『わが家の「ニューロダイバーシティ」ナビゲーター』 (AI Teen Family Neurodiversity Navigator)

## 概要
家族一人ひとりの「脳の特性（認知スタイル）」の違いを、中高生が「ナビゲーター」となってAIと共に紐解き、互いの強みを活かし合える「最高のチーム」としてのわが家をプロデュースするアプリ。ADHDや自閉スペクトラム症といった診断の有無にかかわらず、誰もが持っている「情報の処理の仕方の違い」を可視化し、コミュニケーションのすれ違いを「才能のバリエーション」へと変えていきます。

## 主な機能
- **ブレイン・プロファイリング**: 日常の行動パターンや簡単な認知テストから、AIが家族それぞれの「得意な情報の入り口（視覚・聴覚など）」や「集中の持続パターン」「実行機能の特徴」を分析し、中高生が分かりやすく図解します。
- **「脳タイプ別」コミュニケーション翻訳**: 「何度言っても忘れる」を「聴覚情報の保持が苦手な特性」と翻訳し、AIが「リマインダーの出し方」や「視覚的な伝え方」を提案。中高生が家族間の通訳となって、ストレスのない伝え方をガイドします。
- **環境最適化（ニューロ・デザイン）**: 家族の特性に合わせて、リビングの照明、音環境、物の配置、あるいはスケジュールの組み方をAIがアドバイス。中高生が「集中しやすい空間」や「リラックスできる動線」をプロデュースします。
- **特性シナジー・アサイン**: 旅行の計画や大掃除など、家族のプロジェクトにおいて、それぞれの特性（例：全体俯瞰が得意、細部にこだわるのが得意、瞬発力がある等）を最も活かせる役割分担をAIが提案し、中高生が采配を振るいます。

## 家族にとってのメリット
- **相互理解の深化**: 「性格の不一致」や「やる気のなさ」だと思っていたことが、実は「認知特性の違い」だったと気づくことで、不必要な責め合いが消え、心理的安全性が高まります。
- **個々の能力の最大化**: 自分の特性に合った環境や方法を知ることで、子どもも大人も日々のパフォーマンスが向上し、自信を持てるようになります。
- **ダイバーシティへの深い理解**: 家庭内での実践を通じて、社会における多様性（ニューロダイバーシティ）を尊重する視点が自然と身に付きます。

## ロードマップ
- **v1.0**: 簡易的な特性チェックと、それに基づいた「おすすめの接し方」提案機能。
- **v2.0**: 家族会議で使える「認知スタイル図解」生成と、環境調整（ライティングや音）のアドバイス機能。
- **v3.0**: ウェアラブルデバイス等と連携した「集中・疲労状態」のリアルタイム共有と、特性を活かした家族プロジェクト管理ツール。
