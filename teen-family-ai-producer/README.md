# AI中高生『わが家の「専用AI」』プロデューサー (AI Teen Family "Custom AI" Producer)

## 概要
デジタルツールに精通し、生成AIの活用方法を身につけた中高生が「AIプロデューサー」となり、家族一人ひとりの困りごとやニーズに合わせた「専用AIエージェント」を設計・提供するアプリ。単に既存のAIを使うだけでなく、家族それぞれの性格、好み、生活習慣に合わせたプロンプトエンジニアリングや知識の注入（RAG的なアプローチ）を行い、わが家独自の「AIコンシェルジュ」を作り上げることを支援します。

## 主な機能
- **パーソナルAI・デザイナー**: 家族の性格やニーズをヒアリングし、AIの「キャラ」や「得意分野」を定義。例えば「お父さんの業界ニュース要約AI」「お母さんの残り物アレンジレシピAI」「兄弟のやる気アップ・コーチAI」などを中高生が設計します。
- **わが家専用「知恵の泉」連携**: 家族の過去の予定、好みの味付け、家独自のルールなどをAIに学習させ、一般的なAIには不可能な「わが家事情」を汲み取った回答を生成します。
- **AIリテラシー・コーチ**: 中高生が「AIとの上手な対話術」を親にレクチャー。プロンプトのコツやハルシネーション（嘘）の見分け方を教えることで、家族全員のデジタルリテラシーを向上させます。
- **AIエージェント・メンテナンス**: 家族のフィードバックを受け、中高生が定期的にAIのプロンプトをチューニング。家族の成長や環境の変化に合わせて、AIも常に最適化（アップデート）されます。

## ロードマップ
- **v1.0**: 家族のニーズを抽出するヒアリングテンプレートと、簡単なプロンプト設計ガイド。
- **v2.0**: 家族が直接対話できるUIの提供と、家族固有のドキュメント（メモや写真）のインデックス化支援。
- **v3.0**: 複数のAIエージェントが連携して「家族会議」をシミュレーションしたり、将来の家族の変化を予測したサポートを提案する高度な連携機能。
