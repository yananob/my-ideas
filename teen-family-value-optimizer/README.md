# AI中高生『わが家の「ポイ活・お得」マイスター』 (AI Teen Family Value & Points Optimizer)

## 概要
中高生が「わが家のバリュー最適化担当」となり、複雑なポイント還元（ポイ活）、クーポン、キャッシュバック、ふるさと納税、地域振興券などをAIと駆使して、家族の支出を賢く最適化するアプリ。最新のお得情報をAIが収集・分析し、中高生が家族の「家計の賢者」として家計のゆとりを創出します。

## 主な機能
- **「お得」キュレーション・ダッシュボード**: 家族がよく利用する店舗やサービスに合わせ、AIが最適なポイント還元やクーポン情報をピックアップ。中高生が「今日はこの支払い方法が一番お得だよ」と家族にアドバイスします。
- **ふるさと納税・セレクト・コンシェルジュ**: 家族の好みや必要な備蓄を考慮し、AIがおすすめの返礼品を提案。中高生が寄付額の管理や返礼品の選定をリードし、家族のQOLを向上させます。
- **わが家の「隠れ資産」発掘**: 溜まったまま忘れられているポイントや、期限の近いクーポンをAIが検知。中高生がそれらを有効活用するプラン（例：ポイントで週末の外食を予約するなど）を提案します。
- **バリュー・リテラシー・コーチ**: 複利、還元率、実質価格など、金融リテラシーに関わる知識をAIが中高生にレクチャー。中高生はそれをもとに「なぜこの選択が賢いのか」を家族に説明し、家族全員のマネーリテラシーを高めます。

## ロードマップ
- **v1.0**: 主要なポイントサービスとクーポンの管理・通知機能。
- **v2.0**: ふるさと納税の管理・提案機能と、支払い方法の最適化ガイド。
- **v3.0**: 地域のキャンペーンやニッチなお得情報の自動解析と、家族独自の「節約・投資戦略」の策定支援。
