# AI中高生『わが家の家計・投資』スペシャリスト (AI Teen Family Finance Specialist)

## 概要
高校での金融教育必修化を受け、中高生が「わが家の財務担当（CFO）」として、家族の家計管理や将来の資産形成をAIと共にリードするエージェントです。日々の支出の最適化から、新NISAなどを活用した長期的な資産運用のシミュレーションまで、AIが専門的な知識を分かりやすく中高生にレクチャーし、家族会議での提案をサポートします。実社会で役立つ金融リテラシーを、家族の未来を豊かにする実践を通じて養います。

## 主な機能
- **わが家の家計診断バディ**: 家族の支出データ（匿名化・抽象化可能）をAIが分析し、中高生が「今月は外食が多かったから、来月は自炊を増やして浮いた分を投資に回さない？」といった改善策を家族にプレゼンできるようサポートします。
- **みらい資産シミュレーター**: 教育資金や老後資金など、家族のライフイベントに合わせた長期的な資産形成をシミュレーション。AIがインフレ率や期待リターンを考慮した複数のシナリオを提示し、中高生が家族に最適なプランを提案します。
- **金融リテラシー・ブートキャンプ**: 投資信託、株式、債券、保険などの金融知識を、AIが中高生のレベルに合わせて段階的にレクチャー。最新の経済ニュースがわが家の資産にどう影響するかを分かりやすく解説します。
- **投資体験「サンドボックス」**: 実際の資金を動かす前に、AIが用意した仮想市場で投資の練習。リスクとリターンの関係を体感し、家族で話し合いながら投資方針を固める「予行演習」を提供します。

## ロードマップ
- **v1.0**: 家計簿データの分析と、基本的な資産形成シミュレーション機能。
- **v2.0**: 中高生向けの金融知識学習コンテンツと、家族会議用のプレゼン資料自動作成機能。
- **v3.0**: リアルタイムの経済ニュース連携と、家族独自の「投資ポリシー」策定・運用支援機能。
