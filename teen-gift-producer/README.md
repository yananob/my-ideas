# AI中高生『わが家のギフト』プロデューサー (AI Teen Family Gift Producer)

## 概要
お世話になっている方への贈り物や、家族の記念日のプレゼント。忙しい両親に代わり、中高生がAIを相棒に「ギフト・プロデューサー」となって、わが家の感謝を形にするアプリ。最新のトレンドやエシカルな選択肢を取り入れ、家族の絆と社会との繋がりを深めます。

## 主な機能
- **スマート・ギフト・コンシェルジュ**: 相手の好みや過去の贈り物をAIが分析。中高生のフレッシュな感性とAIの検索力を掛け合わせ、センスの良いギフト候補を提案します。
- **わが家のギフト・ログ**: 誰に何を贈り、どんな反応だったかを一括管理。お返し忘れを防ぎ、家族の「贈り物の歴史」をアーカイブします。
- **サンクス・メッセージ・エディター**: 贈り物に添えるカードやメールの文面を、AIが相手との関係性に合わせて下書き。中高生が最後の一言を添えて、心のこもったメッセージを完成させます。
- **ギフト・バジェット・マネージャー**: 家族全体の年間ギフト予算を管理。中高生が限られた予算内で最高のパフォーマンス（喜び）を引き出すプランを立案します。

## ロードマップ
- **v1.0**: ギフト候補のAI検索と、シンプルな送付先リスト管理機能。
- **v2.0**: 過去の履歴に基づいたリマインド機能と、メッセージカードの自動生成。
- **v3.0**: 地域の名産品やエシカル商品に特化した「ストーリーのあるギフト」提案機能。
