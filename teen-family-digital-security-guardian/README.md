# AI中高生『わが家の「デジタル・セキュリティ」ガーディアン』 (AI Teen Family Digital Security Guardian)

## 概要
AI技術を悪用した巧妙な詐欺（ボイスクローンによるなりすまし、ディープフェイク等）や、進化し続けるサイバー攻撃から家族を守るため、中高生が「デジタル・セキュリティ・ガーディアン」となって家族の安全をリードするアプリ。デジタルネイティブな感性とAIの分析力を組み合わせ、家族全員のデジタルリテラシー向上と安全な環境作りを中高生主導で実現します。

## 主な機能
- **AI詐欺・なりすまし対策講座**: 最新のAIを悪用した詐欺事例（ボイスクローン詐欺など）をAIが要約・提供。ガーディアンはそれを家族にレクチャーし、緊急時の「わが家だけの秘密の合言葉」の設定などをプロデュースします。
- **ファミリー・デジタル監査（監査モード）**: 家族全員のパスワードの強度、二要素認証の設定状況、過去のデータ漏洩履歴などをAIと協力して定期的にチェック。改善が必要なポイントを「セキュリティ診断レポート」として提示します。
- **プライバシー・ガード・アドバイザー**: SNSの投稿内容やアプリの権限設定をAIがスキャンし、意図しない位置情報の公開やプライバシーリスクを警告。家族のデジタルフットプリントを健全に保つためのアドバイスを行います。
- **ディープフェイク/フィッシング検知バディ**: 怪しい動画やメール、メッセージをAIで解析し、偽造の可能性やリスクを判定。家族が「これ、本物かな？」と迷った時の相談窓口としてガーディアンが機能します。

## 家族にとってのメリット
- **最新リスクへの即応**: 急速に進化するAI詐欺に対し、感度の高い中高生が中心となることで、家族全体の防衛力が飛躍的に高まります。
- **安心の共有**: 「何が危険か」を家族で共有し、具体的な対策（合言葉など）を持つことで、心理的な安全性が向上します。
- **中高生の責任感とリテラシー**: 家族を「守る」役割を担うことで、倫理観、責任感、そして高度なデジタルリテラシーが育まれます。

## ロードマップ
- **v1.0**: パスワード強度チェックと、最新詐欺事例の要約・レクチャー支援機能。
- **v2.0**: SNSのプライバシー設定監査機能と、家族間での「安全プロトコル（合言葉等）」管理機能。
- **v3.0**: AIによる高度なディープフェイク検知支援と、地域や高齢の親戚も巻き込んだ「デジタル安全ネットワーク」への拡張。
