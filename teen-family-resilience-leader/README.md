# AI中高生『わが家のレジリエンス・リーダー』 (AI Teen Family Resilience Leader)

## 概要
デジタル技術に強い中高生が「レジリエンス（復元力）・リーダー」となり、災害、ネット障害、情報セキュリティ、電力不足など、現代の家庭が直面する様々なリスクから家族を守り、迅速に復旧するための「わが家の生存戦略」をAIと構築するアプリ。

## 主な機能
- **デジタル・アセット・セーフガード**: 重要書類の暗号化バックアップや、緊急時のオフラインアクセス手順をAIがガイド。
- **わが家の電力・通信シミュレーター**: 停電や通信障害が発生した際のデバイスのバッテリー管理や代替通信手段（オフラインマップ等）をAIと最適化。
- **インフォメーション・サバイバル・チェック**: 災害時や緊急時のデマ情報を見極め、信頼できるソースからの情報収集をAIがサポート。
- **レジリエンス・訓練プロデュース**: 避難訓練だけでなく、「スマホが使えない1日」などのデジタル・デトックス訓練をAIと企画し、家族の対応力を高める。

## ロードマップ
- **v1.0**: 備蓄管理とデジタルバックアップ支援。
- **v2.0**: オフライン環境での情報提供機能。
- **v3.0**: スマートホーム機器と連携した自動リスク検知と復旧ガイド。
