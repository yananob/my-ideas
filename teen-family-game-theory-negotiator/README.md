# AI中高生『わが家の「ゲーム理論」交渉官』 (AI Teen Family Game Theory Negotiator)

## 概要
家族内のリソース配分やルール作りは、感情的な対立になりがちです。このアプリは、中高生が「ゲーム理論」の専門家となり、AIのサポートを受けて家族間の利害を調整するエージェントです。論理的で客観的なフレームワーク（ナッシュ均衡、パレート改善、メカニズムデザインなど）を用いることで、「誰かが我慢する」のではなく、家族全員の満足度を最大化する「最適解」を導き出します。

## 主な機能
- **ファミリー・ペイオフ・マトリクス**: 「お風呂の順番」「家事の分担」「共有スペースの使い方」などの課題に対し、家族それぞれの「得（満足度）」と「損（負担）」を数値化して可視化。AIが複数の選択肢の中から、全員にとって納得感のある均衡点を提示します。
- **Win-Winメカニズム・デザイン**: 「どうすればみんなが自発的に協力したくなるか」という仕組みをAIと設計します。例えば、インセンティブ（報酬）や罰則の設計、あるいは「あみだくじ」よりも公平な順番決めアルゴリズムを提案します。
- **戦略的ファシリテーション・バディ**: 家族会議の際、AIが中高生に「今は相手の譲歩を引き出すタイミングだよ」「こういう代案を出すと合意しやすいよ」といった交渉のアドバイスをリアルタイムで提供します。
- **リソース・オークション**: チャンネル権や家事の免除などを「家族内ポイント」で競り合うオークション形式を導入。市場原理を取り入れることで、最もそのリソースを必要としている人が正当に獲得できる仕組みをプロデュースします。

## 家族にとってのメリット
- **感情的な対立の解消**: 議論が「誰が正しいか」から「どの数値（均衡点）が最適か」に移るため、不必要な喧嘩が減ります。
- **論理的思考と社会スキルの習得**: 中高生が社会のルール設計にも使われる高度な知見を実生活で活用し、交渉力や調整力を身につけることができます。
- **納得感のあるルール運用**: 自分が意思決定プロセスに参加し、論理的に導き出された結論であるため、決まったルールを守る意欲が高まります。

## ロードマップ
- **v1.0**: シンプルな損益表（ペイオフマトリクス）の作成と、代表的なゲーム理論モデルの適用支援。
- **v2.0**: 家族会議中の音声から対立点を抽出し、解決策をリアルタイムで提案する交渉支援機能。
- **v3.0**: 家族独自の経済圏（ポイント・トークン）の発行・管理と、それに基づいたリソース配分アルゴリズムの自動化。
