# AI中高生『家族の自由研究』ラボ (AI Teen Family Lab)

## 概要
家族の生活の中にある「課題」や「もっと良くしたいこと」をテーマに、中高生が「研究責任者」となって、データ分析や実験を通じて解決を目指すAIエージェントです。親が一方的にルールを決めるのではなく、子どもが主導して「わが家に最適な仕組み」を科学的にデザインすることをサポートします。論理的思考やデータリテラシーを育みながら、家族を一つの「チーム」としてより良くしていく体験を提供します。

## 主な機能
- **実験デザイン・エージェント**: 「どうすれば朝の洗面所の渋滞を解消できるか？」「どのスーパーで買うのが一番コスパが良いか？」といった問いに対し、仮説の立て方やデータ収集の方法（ログの取り方など）をAIがアドバイスします。
- **データ・ビジュアライザー**: 家族が記録したログ（時間、金額、感情指数など）をAIが解析し、グラフやチャートで可視化します。「実は水曜日が一番忙しい」といった客観的な事実を家族で共有可能にします。
- **ルール・プロトタイピング**: 分析結果に基づき、「1週間だけこの新しいルールを試してみよう」というプロトタイプ（試行案）を提案。AIがその実施状況をトラッキングし、期間終了後に振り返りを支援します。
- **ラボ・レポート作成**: ひとつのプロジェクトが終わるごとに、研究の背景、方法、結果、今後の課題をまとめたレポートを自動生成。家族の「改善の歴史」として蓄積されます。

## ロードマップ
- **v1.0**: 実験テーマの相談機能と、手動入力ベースのログ収集・グラフ化機能。
- **v2.0**: スマートフォンの歩数データや位置情報、家計簿アプリ等との連携による自動データ収集機能。
- **v3.0**: 専門家（経済学者、心理学者、家事のプロなど）の視点を取り入れた「高度な分析アドバイス」機能。
