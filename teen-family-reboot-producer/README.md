# AI中高生『わが家の「やり残し」再起動プロデューサー』 (AI Teen Family "Unfinished Business" Reboot Producer)

## 概要
家族の過去の「挫折」や「やり残し」を、中高生がAIと共にポジティブに再解釈（リフレーミング）し、新しい形での完成や再起動をプロデュースするアプリ。クローゼットの奥で眠る作りかけのプラモデル、数ページで止まった語学テキスト、計画倒れになった旅行プランなど、わが家の「負の遺産」を「クリエイティブな資産」へと変え、家族の挑戦心を再び燃え上がらせます。

## 主な機能
- **わが家のお宝（やり残し）スキャナー**:
  家の中に眠る「やり残したモノ」を写真に撮ったり、AIと対話してリスト化します。AIがその時の熱量や、なぜ止まってしまったのかを優しくヒアリングし、データベース化します。
- **挫折の「リフレーミング」提案**:
  AIが、過去の挫折を「今の自分たちならどう楽しめるか」という視点で再定義。例えば「止まったままのフランス語学習」を「AI翻訳を駆使した、わが家独自の創作物語作り」に変換したり、「作りかけのDIY」を「あえて未完成を活かしたアート作品」として再起動させます。
- **AI「第二の伴走者」マッチング**:
  再起動するプロジェクトに対し、AIが最適な「相棒キャラクター」や「学習ステップ」を生成。中高生がそのプロデューサーとなり、親が無理なく、かつ楽しく再開できるよう、日々の小さな進捗（ベビーステップ）をデザインします。
- **「やり残し」成仏・祝祭システム**:
  どうしても再開しないと決めたモノに対しては、AIがその挑戦が家族に与えた「学び」を言語化。感謝と共に手放したり、別の何かの部品として転生（アップサイクル）させたりする「卒業式」をプロデュースします。

## 家族にとってのメリット
- **自己肯定感の回復**: 「やり残し」という小さな心のしこりが解消されることで、家族全員の心理的な軽やかさと自信が戻ります。
- **中高生のプロデュース力**: 過去の失敗を「素材」として捉え、最新技術（AI）を駆使して新たな価値を生み出す、高度なクリエイティブ・リーダーシップが養われます。
- **家族の絆の再確認**: 過去の共通の思い出や目標を振り返ることで、家族の歩みを肯定的に捉え直す機会となります。

## ロードマップ
- **v1.0**: 「やり残し」の記録と、AIによるシンプルなリフレーミング（言い換え）提案機能。
- **v2.0**: 画像生成AIによる「完成予想図（リブート案）」のビジュアル化と、進捗管理機能。
- **v3.0**: 外部のリサイクル・アップサイクルサービスとの連携、および地域で「やり残し」を交換・補完し合うコミュニティ機能。
