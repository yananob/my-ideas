# AI中高生『わが家の「ラーニング・ポートフォリオ」プロデューサー』 (AI Teen Family Learning Portfolio Producer)

## 概要
日々の仕事や家事、趣味、ボランティアなど、家族一人ひとりの「学び」や「挑戦」は、形に残りにくく、その価値が見過ごされがちです。このアプリは、情報整理と価値の再定義を得意とする中高生が「ポートフォリオ・プロデューサー」となり、AIと共に家族の活動を記録・構造化。個人の成長を可視化し、キャリアや自己実現の資産（ポートフォリオ）としてプロデュースします。

## 主な機能
- **「学びの原石」キャプチャ**: 家族がその日に行ったこと、感じたことをAIとの短い対話や写真で記録。AIがその中から「スキルの習得」「価値観の深化」「困難の克服」といった学びの要素を抽出します。
- **AIスキル・マッピング**: 蓄積された記録をAIが分析し、個人の強みや獲得したスキルを多角的に可視化。本人も気づいていない「ポータブルスキル」や、その人独自の「専門性」を中高生が再定義し、ラベル付けします。
- **ストーリー仕立てのポートフォリオ生成**: 単なる実績の羅列ではなく、どのような背景で、どのような試行錯誤を経て、何を得たのかという「成長の物語」をAIが構成。中高生が最終的な表現をプロデュースし、LinkedInや社内評価、地域活動での自己紹介などに使える形に整えます。
- **ファミリー・アチーブメント・セレブレーション**: 週末や月末に、家族それぞれの「今週のベスト・ラーニング」を発表。成果だけでなく、その過程にある努力や工夫を家族で称え合う culture を育みます。

## 家族にとってのメリット
- **自己肯定感の向上**: 日々の当たり前の活動に価値を見出し、自分の成長を実感することで、家族全員の自信に繋がります。
- **キャリア資産の構築**: いざ転職や新しい挑戦をしようとした際、自分の経験が既に構造化されているため、強力な武器になります。
- **相互リスペクトの深化**: 家族が外でどのような挑戦をしているかを知ることで、互いを一人の自律した人間としてより深く尊敬し合えるようになります。

## ロードマップ
- **v1.0**: AIとのチャットによる活動記録機能と、タグ付け・分類の自動化。
- **v2.0**: スキルの成長をグラフ化するダッシュボードと、標準的なポートフォリオ・テンプレートの提供。
- **v3.0**: 外部のスキル証明（バッジ等）との連携や、生成AIを活用した「自己紹介動画」の自動構成・演出機能。
