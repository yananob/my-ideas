# AI中高生『わが家の「夢・分析」プロデューサー』 (AI Teen Family Dream Producer)

## 概要
家族が就寝中に見た「夢」をAIで記録・可視化・分析し、中高生が「夢・分析プロデューサー」として家族の深層心理や創造性をプロデュースするアプリ。普段の会話では見えてこない家族の想いやストレス、豊かな想像力を共有することで、家庭内の相互理解を深め、メンタルケアや創造的な対話のきっかけを作ります。

## 主な機能
- **ドリーム・キャプチャ**: 起床直後の断片的な夢の記憶をAIとの対話で引き出し、構造化された「夢日記」として記録します。
- **AIドリーム・イラストレーター**: 記録された夢の内容を画像生成AIがビジュアル化。抽象的で不思議な夢の世界を、家族で共有できる「作品」に変えます。
- **深層心理インサイト**: 心理学的な知見とAIの分析を組み合わせ、夢に現れたシンボルや感情から、家族が今抱えている関心事やストレス、潜在的な願いを「インサイト」として中高生に提示します。
- **ファミリー・ドリーム・シアター**: 週末などに、家族それぞれの夢をショートストーリーやアートとして発表し合う時間をプロデュース。互いの内面世界を尊重し、刺激し合うクリエイティブな場を作ります。

## 家族にとってのメリット
- **深い相互理解**: 言葉にしにくい感情や潜在的な想いを、夢を通じて理解し合うことができます。
- **創造性の刺激**: 夢のビジュアル化を通じて、家族全員の想像力を育み、アートや物語を楽しむ文化が生まれます。
- **心理的ケア**: ストレスや不安が夢に現れた際、AIのアドバイスを元に中高生がさりげなく家族をサポートするきっかけが得られます。

## ロードマップ
- **v1.0**: 音声対話による夢の記録機能と、画像生成AIによる夢のシーンの可視化。
- **v2.0**: 夢の傾向分析（ドリーム・トレンド）と、心理学的知見に基づく簡易的なインサイト提示機能。
- **v3.0**: ウェアラブルデバイスの睡眠データ（レム睡眠のタイミング等）との連携による、より精度の高い記録支援とメンタルヘルス予測。
