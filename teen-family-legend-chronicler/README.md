# AI中高生『わが家の「伝説」編纂者』 (AI Teen Family "Legend" Chronicler)

## 概要
家族の何気ない日常のエピソード、親や祖父母から聞いた昔話、さらには家系図に連なる先祖の記録を、中高生が「編纂者」となり、AIの力を借りて壮大な「物語（レジェンド）」へと昇華させるアプリ。家族の歩みを英雄譚、ファンタジー、あるいは歴史小説のような文体で記録し直すことで、家族のアイデンティティを再定義し、世代を越えた絆と誇りを育みます。

## 主な機能
- **エピソード・エピック変換**: 「今日、お父さんが夕飯を作ってくれた」といった日常の出来事や、「昔、おじいちゃんが起業した時の話」などを入力すると、AIが「勇者が新たな領地を切り拓いた物語」のような壮大な文体に変換します。
- **ファミリー・アーカイブ・インタビュー**: AIが編纂者（中高生）に、家族の歴史を深掘りするための質問を提案。インタビュー音声を解析し、事実関係を整理しながら物語のプロットを構築します。
- **レジェンド・ビジュアライザー**: 構築された物語に基づき、家族をキャラクター化した挿絵や、家系の歴史を記した「古地図風の家系図」を画像生成AIで作成。物語の世界観を視覚的に彩ります。
- **叙事詩「わが家の史書」発行**: 蓄積された物語を、一つの壮大な「家族史」としてデジタルブック化。節目のイベント（誕生日や正月など）で朗読したり、親戚と共有したりすることで、家族の伝統を未来へ繋ぎます。

## ロードマップ
- **v1.0**: テキストベースの物語変換機能（各種文体選択可能）と、シンプルなインタビュー記録機能。
- **v2.0**: 画像生成AIによるキャラクター・背景画像の作成支援と、デジタル家系図作成機能。
- **v3.0**: 複数の家族メンバーが共同で編集できる「マルチコンパイラー」機能と、ナレーション付きの「動く物語（オーディオブック風）」生成機能。
