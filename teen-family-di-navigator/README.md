# AI中高生『わが家の「ダイバーシティ＆インクルージョン」ナビゲーター』 (AI Teen Family D&I Navigator)

## 概要
多様性（Diversity）と包摂（Inclusion）への理解が深い中高生がリーダーとなり、家族全員が異なる価値観や背景を尊重し合い、誰もが自分らしく心地よく過ごせる「開かれたわが家」をAIと共にプロデュースするアプリ。

## 主な機能
- **ダイバーシティ・ダイアログ・スターター**: ニュースやSNSで話題の多様性に関するトピック（ジェンダー、多文化、バリアフリーなど）をAIがピックアップ。夕食時などに家族でフラットに話し合えるきっかけを提供します。
- **インクルーシブ・ホーム・チェック**: 家の中の言葉遣いや環境が、誰かにとって無意識に排他的になっていないかをAIと点検。「誰にとっても心地よい空間」にするためのアクションを提案します。
- **グローバル・バリュー・コネクター**: 世界中の多様な文化や価値観を持つ人々のストーリーをAIがキュレーション。家族の視野を広げ、ステレオタイプを解消するための学びをサポートします。
- **ファミリー・ウェルカム・プロデュース**: 親戚や友人が来訪する際、相手の背景（食事の制限、文化、習慣など）に合わせた「最高のおもてなし」をAIとプランニングし、多様な人々を温かく迎える準備をします。

## ロードマップ
- **v1.0**: 多様性に関するニュースの要約と、対話のヒントとなる質問カード機能。
- **v2.0**: 家族のアンコンシャス・バイアス（無意識の偏見）を可視化するクイズと、インクルーシブな環境作りのアドバイス。
- **v3.0**: 地域の外国人住民や多様な背景を持つ人々との交流イベントとのマッチング、および「わが家のダイバーシティ憲章」の策定支援。
