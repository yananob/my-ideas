# AI中高生『わが家の「クリエイティブ・コーディング」メンター』 (AI Teen Family Creative Coding Mentor)

## 概要
デジタル技術に親しみ、プログラミングを学ぶ中高生が「メンター（指導者）」となり、AIのサポートを受けながら家族にコードの楽しさやクリエイティブな表現を教えるアプリ。AIが個々のレベルに合わせた学習プランやコードの解説、バグの診断をサポートすることで、中高生は教えることを通じて自身の理解を深め、家族全員でテクノロジーを活用した創造的な時間を共有します。

## 主な機能
- **ファミリー・プログラミング・カリキュラム**: 家族の興味（「動くアートを作りたい」「ゲームを作りたい」など）に合わせて、中高生メンターとAIが最適な学習ロードマップを作成します。
- **AIペアプログラミング・アシスト**: 家族がコードを書く際、AIがリアルタイムでヒントや解説を提供。中高生はそれを補足したり、より分かりやすい例え話で教えたりすることで、ティーチング・スキルを磨きます。
- **わが家のデジタル・ギャラリー**: 家族が作ったプログラム（ジェネレーティブ・アート、簡単なゲーム、便利ツールなど）を展示・共有するギャラリー機能。AIが作品の素敵なポイントを講評し、家族のモチベーションを高めます。
- **コードで解決！わが家の不便**: 「家事の当番をランダムで決めるツール」や「家族の記念日カウントダウン」など、生活に役立つ小さなツールを家族で協力して開発するプロジェクトをAIがガイドします。

## ロードマップ
- **v1.0**: ビジュアルプログラミング（Scratch等）や簡単なPythonコードを対象とした学習ガイドと、AIによる解説機能。
- **v2.0**: 画像生成AIや音楽生成AIと連携し、コードでこれらを制御する「クリエイティブ・アート」コースの追加。
- **v3.0**: 開発したツールを家庭内のスマートデバイスやウェブ上で実際に運用するためのデプロイ支援機能。
