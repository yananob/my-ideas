# AI中高生『わが家の「おもてなし」コンシェルジュ』 (AI Teen Family Hospitality Concierge)

## 概要
中高生が「わが家のコンシェルジュ」となり、AIの力を借りて来客（祖父母、親戚、友人など）に対してパーソナライズされた最高の「おもてなし」をプロデュースするアプリ。デジタルネイティブな感性とAIの分析力を活かし、単なる接待を超えた、ゲストの心に残る体験をデザインします。

## 主な機能
- **ゲスト・プロファイル・アナライザー**: ゲストの好み、アレルギー、興味関心、過去の会話内容などをAIが整理。それに基づき、最適なウェルカムドリンク、食事のメニュー、BGM、話題などを提案します。
- **「おもてなし」プランナー**: 滞在中のタイムスケジュールや、近隣の観光・散歩ルート、家でのリラックスプランをAIと一緒に作成。ゲストの年齢や体調に合わせた無理のないプランを提示します。
- **スマート・ルーム・セッティング**: ゲストが過ごす部屋の照明、温度、香り（アロマ）、スマートスピーカーのプレイリストなどを、ゲストの好みに合わせてAIが自動調整・設定サポート。
- **デジタル・サンクス・ギフト**: 滞在中の写真や動画をAIが編集し、帰宅後のゲストに贈る「デジタル思い出アルバム」や「感謝のメッセージカード」を自動生成。

## ロードマップ
- **v1.0**: ゲスト情報の管理と、おもてなしプラン（食事・話題）の提案機能。
- **v2.0**: スマートホームデバイスとの連携による空間演出の自動化と、近隣ガイドの生成機能。
- **v3.0**: 過去のおもてなし記録を学習し、回を重ねるごとに精度が増す「わが家流おもてなし」のナレッジベース化。
