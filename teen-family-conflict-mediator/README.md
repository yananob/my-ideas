# AI中高生『わが家の「コンフリクト・メディエーター」』 (AI Teen Family Conflict Mediator)

## 概要
家族の間で意見が対立したり、感情的な衝突が起きたりしたとき、中高生が「メディエーター（調停役）」として介入し、AIの客観的な視点を借りながら円満な解決をプロデュースするアプリ。デジタルネイティブとしての論理的思考と、AIによる多角的な分析を組み合わせ、単なる「言い合い」を「未来のための合意形成」へとアップデートします。

## 主な機能
- **コンフリクト・マッピング**: 衝突している原因（リソースの不足、価値観の相違、コミュニケーションのミスなど）をAIがインタビューから構造化。何が本当の論点なのかを可視化します。
- **感情の「翻訳」バディ**: 売り言葉に買い言葉になりがちな感情的な言葉を、AIが「その裏にある本当の願い（ニーズ）」に翻訳。中高生がその翻訳結果を家族に伝えることで、共感の土台を作ります。
- **「第三の道」シミュレーター**: A案（親の主張）とB案（子の主張）のどちらかを選ぶのではなく、双方が納得できる「第3の解決案（C案）」をAIが複数提案。中高生がそれぞれの案のメリット・デメリットをプレゼンします。
- **未来の「合意契約書」作成**: 話し合いの結果を、AIがポジティブな言葉で「わが家の合意契約書」としてまとめます。単なるルール設定ではなく、お互いの信頼を深めるための約束事としてアーカイブします。

## 家族にとってのメリット
- **感情的な対立の減少**: 第三者（AIと中高生）が介在することで、冷静な話し合いが可能になり、家庭内のストレスが軽減されます。
- **中高生のリーダーシップ向上**: 複雑な人間関係の調整を、論理と共感の両面からリードする経験を通じて、高度なコミュニケーション能力と解決能力が育まれます。
- **心理的安全性の強化**: 「意見が違っても、必ず解決できる」という安心感が家族に根付き、よりオープンな対話ができる文化が育ちます。

## ロードマップ
- **v1.0**: 衝突内容のインタビューと論点整理（マッピング）機能。
- **v2.0**: 感情の翻訳機能と、AIによる「第3の道」提案エンジンの実装。
- **v3.0**: 過去の解決事例（成功パターン）を学習し、わが家独自の「コンフリクト解決ナレッジベース」を構築する機能。
