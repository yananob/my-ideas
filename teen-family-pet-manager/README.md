# AI中高生『わが家のペット・マネージャー』 (AI Teen Family Pet Manager)

## 概要
家族の大切な一員であるペット（犬、猫、小動物など）の健康管理やしつけ、日々のケアを、中高生が「ペット・マネージャー」となってAIと共にリードするアプリです。最新の動物行動学や獣医学に基づいたAIのアドバイスを受けながら、中高生が主体となってペットの幸福（アニマル・ウェルビーイング）を追求し、家族全員で愛情を深めるためのプラットフォームを提供します。命を預かる責任感と、データに基づく論理的なケアの手法を養います。

## 主な機能
- **AIペット健康モニタリング**: 食事量、排泄、活動量、体重などの日々の記録をAIが解析。「最近少し食欲が落ちているかも」「運動不足気味だよ」といった微細な変化をマネージャーに通知し、適切なアクション（獣医への相談や食事調整）を促します。
- **アニマル・コミュニケーション・トレーニング**: ペットの鳴き声や仕草、表情をカメラやマイクで捉え、AIがその感情を推測。マネージャーが「今は遊びたいみたいだよ」「ちょっと疲れちゃったかも」と家族に伝え、より良い関係を築くためのしつけや接し方をAIがガイドします。
- **ファミリー・ケア・アサインメント**: 散歩、ブラッシング、ケージの掃除など、家族全員の役割分担をマネージャーがAIと調整。リマインドを送り、完了したタスクを「ペットからの感謝」として可視化することで、家族の協力体制を楽しく構築します。
- **ペットの『生涯アルバム』ディレクション**: 日々の何気ない写真や動画をAIが整理し、その時の体調や行動記録と紐づけたデジタル・ライフログを作成。将来の受診時に役立つ「ペットの履歴書」や、家族の宝物となる「成長物語」をプロデュースします。

## ロードマップ
- **v1.0**: 日々の健康記録（食事、排泄、体重）と、AIによる基本的な健康分析・アドバイス機能。
- **v2.0**: 画像・音声解析による感情推測機能と、家族間での役割分担・リマインド機能。
- **v3.0**: 提携オンライン獣医相談サービスとの連携や、ウェアラブルデバイス（スマート首輪等）とのデータ同期機能。
