# AI中高生『わが家の「感性」プロデューサー』 (AI Teen Family Aesthetic Producer)

## 概要
中高生が「感性プロデューサー」となり、AIと共に家族の生活に「美しさ」「心地よさ」「文化的刺激」を取り入れるためのエージェントです。最新のトレンドや多様な文化に敏感な中高生ならではの視点で、音楽、アート、映画、食文化などをキュレーションし、家族の情緒的な暮らしをアップデートします。

## 主な機能
- **カルチャー・キュレーション**: 家族のその時の気分や季節に合わせ、中高生の感性で選んだ音楽、映画、本をAIが背景情報と共にレコメンド。単なる「おすすめ」ではなく、なぜ今これが必要かを家族に提案します。
- **デジタル・ホームギャラリー**: 生成AIを活用したアート制作や、世界中の名画のデジタル展示を家庭内のディスプレイにディレクション。時間帯や天気に合わせた「わが家の雰囲気」を演出します。
- **センスアップ・ダイニング**: 特定のテーマ（例：北欧の夜、昭和レトロ、近未来など）に合わせたBGM、テーブルセッティング、文化的背景知識をプロデュースし、いつもの食卓を特別な体験に変えます。
- **インスピレーション・ログ**: 家族が見つけた「心が動いた言葉」や「美しい風景」をAIが共有・蓄積し、わが家独自の「感性図鑑」を作り上げます。

## ロードマップ
- **v1.0**: 気分に合わせたプレイリストと映画の提案機能、および簡単な「今日の言葉」共有機能。
- **v2.0**: 画像生成AIと連携した、リビング用デジタルアートの生成・管理機能。
- **v3.0**: 地域の美術館やイベント情報と連携した「お出かけ感性プランニング」機能と、ARを活用した空間装飾シミュレーション。
