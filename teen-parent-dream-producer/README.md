# AI中高生『親の「やりたい」応援プロデューサー』 (AI Teen Parent's Dream Producer)

## 概要
「親が自分のために時間を使えるようになってほしい」と願う中高生が、AIを相棒にプロデューサーとなり、親の眠っていた夢や新しい挑戦を全力で応援するアプリ。親子の役割を少しだけスイッチすることで、互いの自立と成長を支え合う新しい家族の形を提案します。

## 主な機能
- **夢の掘り起こしインタビュー**: AIが中高生に「親への質問案」を提示。幼少期の夢や、今密かに興味があることを楽しく聞き出すインタビューをサポートします。
- **親子でつくる「やりたいこと」リスト**: 聞き出した内容をAIが整理し、実現可能なスモールステップに分解。親子で共有できるバケットリストを作成します。
- **応援アクション・プランナー**: 「この日は自分が夕飯を作るから、お母さんは習い事に行って」など、親の挑戦を支えるための家族内の役割分担をAIが最適化。
- **サプライズ・マイルストーン祝賀**: 親が小さな目標を達成したとき、AIが中高生に「お祝いのアイデア（演出やメッセージ）」を提案。達成感を家族で共有します。

## ロードマップ
- **v1.0**: インタビュー支援機能と、共有バケットリストの作成機能。
- **v2.0**: 家族のスケジュールと連携した応援プランニング機能と、モチベーション維持のためのリマインド機能。
- **v3.0**: 親が挑戦している分野のコミュニティやリソースをAIが調査し、中高生が「最新情報」として親に提供する機能。
