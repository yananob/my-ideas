# AI中高生『わが家の「ルーツ」探求プロデューサー』 (AI Teen Family Roots Explorer)

## 概要
中高生が「探求プロデューサー」となり、家族の歴史（家系）を最新のAI技術と公開データ、家族へのインタビューを通じて調査・分析するアプリ。単なる家系図作りにとどまらず、家族の歩みを当時の世界情勢や地域史と紐付けることで、自分たちの存在が歴史の大きな流れの一部であることを実感し、家族のアイデンティティと誇りを次世代へ繋ぎます。

## 主な機能
- **AI家系リサーチ・バディ**: 散逸している古い戸籍謄本や位牌、親戚の話から得られた情報をAIが構造化。不足している情報を補完するための公的調査ガイドや、高度な検索クエリを中高生に提供します。
- **歴史コンテキスト・リンカー**: 家族のライフイベント（移住、転職、結婚など）を、当時の社会情勢や歴史的事件と自動で紐付け。「なぜあの時、祖父はあの大都市へ移ったのか？」といった背景をAIが当時の経済状況などから推測・解説します。
- **祖先マップ・ビジュアライザー**: 祖先がどこから来て、どのように移動してきたのかを、時代背景とともに地図上に視覚化。苗字の由来や、地域特有の文化との関連性もAIが分析します。
- **ファミリー・オリジン・レポート**: 調査結果を、一冊の「探求報告書」としてAIが自動編集。中高生が「編集長」として、家族へのサプライズ・プレゼンテーションを行うためのスライド資料も生成します。

## 家族にとってのメリット
- **アイデンティティの再発見**: 自分のルーツを知ることで、中高生の自己肯定感や「歴史の当事者」としての意識が育まれます。
- **多世代間の深い対話**: 調査の過程で祖父母や親にインタビューを行うことで、普段聞けない苦労話や想いを共有する貴重な機会が生まれます。
- **歴史への多角的な興味**: 家族という極めて個人的な視点から歴史を捉え直すことで、教科書上の知識ではない、生きた歴史への関心が深まります。

## ロードマップ
- **v1.0**: 家系情報の入力と、AIによる年表作成・基本的な歴史イベントの自動紐付け機能。
- **v2.0**: 地図ベースの移動履歴可視化と、インタビュー用のAIガイド（深掘り質問案の生成）。
- **v3.0**: 地域の郷土史データベースや名字由来データベースとのAPI連携による、より精緻な背景分析機能。
