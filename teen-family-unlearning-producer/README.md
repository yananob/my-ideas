# AI中高生『わが家の「アンラーニング」プロデューサー』 (AI Teen Family "Unlearning" Producer)

## 概要
AI時代において最も重要なスキルの一つと言われる「アンラーニング（学習棄却）」。かつての成功体験や「当たり前」だと思っていた習慣が、今の変化の足かせになっていることに気づくのは難しいものです。このアプリは、先入観の少ない中高生が「プロデューサー」となり、親や家族が持っている「古くなった当たり前」をAIと共に発見し、手放し、新しい価値観にアップデートするプロセスを支援します。

## 主な機能
- **「当たり前」棚卸しヒアリング**: AIが提示する質問に親が答えることで、無意識に持っている固定観念や古い習慣を可視化。中高生プロデューサーが「それって今の時代も必要かな？」と客観的にフィードバックします。
- **古い習慣デトックス・プログラム**: 「メールの儀礼的な挨拶を減らす」「紙の資料を全廃する」など、手放すべき具体的な習慣をリスト化。中高生がAIと連携して、代わりとなるモダンな代替案を提案し、移行をサポートします。
- **「常識」ハック・ミッション**: 家族が「無理だ」「こうあるべきだ」と思っていることに対し、AIが世界中の最新事例や異なる価値観を提示。中高生がガイドとなり、一週間限定でその「常識」を外してみる実験を家族に課します。
- **世代間ギャップ・アップデート**: 親世代の「当たり前」と中高生世代の「普通」をAIが対比し、相互理解を深めるためのワークショップを定期的に開催。家族全体のOSを常に最新状態に保ちます。

## 家族にとってのメリット
- **変化への適応力向上**: 親が自らの価値観を柔軟に更新できるようになることで、AI時代の変化を恐れず、チャンスとして捉えられるようになります。
- **心理的安全性の醸成**: 「間違い」を指摘するのではなく「更新」を祝う文化ができることで、家族間のコミュニケーションがポジティブかつオープンになります。
- **親のキャリアと人生の活性化**: 古い枠組みから解放されることで、親自身が新しい挑戦を始めたり、より自分らしい生き方を見つけたりするきっかけになります。

## ロードマップ
- **v1.0**: AIによる思考のクセ発見ヒアリング機能と、アンラーニング推奨リスト。
- **v2.0**: 古い習慣を手放すための「デトックス・クエスト」と、代替ツール導入支援。
- **v3.0**: 家族全体の「思考の柔軟度」の推移を可視化するレポート機能と、アンラーニング成功事例の共有。
