# AI中高生『自立への挑戦』バディ (AI Teen Independence Challenge Buddy)

## 概要
一人暮らしや社会人への準備を始める中高生と、その成長を見守る保護者のための自立支援アプリです。「将来、親がいなくても困らない力」を、身近な家事、金銭管理、行政手続きなどの「クエスト」を通じて親子で楽しみながら育みます。親が教えるのではなく、AIが「コーチ」として伴走することで、反抗期でもスムーズにスキルを習得できる環境を提供します。

## 主な機能
- **サバイバル・スキル・クエスト**: 「一人分のご飯を1000円で作る」「役所で住民票を取る（擬似体験）」「公共料金の仕組みを知る」など、自立に必要なスキルをクエスト形式で学習。AIが手順をガイドし、完了したら写真やクイズで報告します。
- **自律家計簿バディ**: お小遣いやバイト代の管理をサポート。AIが「今月このペースだと、欲しかったアレが買えなくなるかも？」とアドバイスし、計画的な支出を促します。
- **ペアレンツ・スポンサー機能**: 子どもがクエストをクリアすると、親に「〇〇のスキルを習得しました！」と通知。親は「ご褒美（追加のお小遣いや自由時間など）」を設定でき、子どもの努力を正当に評価できます。
- **自立への対話（ライフデザイン）**: 「将来どんなところに住みたい？」「月いくらあれば生活できると思う？」といった問いかけをAIが行い、理想のライフスタイルと現実的なコスト感覚を養います。

## ロードマップ
- **v1.0**: 基本的な家事クエスト（料理、掃除、洗濯）と進捗管理機能。
- **v2.0**: 金銭管理機能（簡易家計簿）と、親からのインセンティブ設定機能。
- **v3.0**: 社会的な手続き（保険、契約、行政）の学習コンテンツと、将来の生活費シミュレーター。
