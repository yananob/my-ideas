# AI中高生『わが家の「アルゴリズム・ナビゲーター」』 (AI Teen Family Algorithm Navigator)

## 概要
SNSや動画プラットフォームの「レコメンドアルゴリズム」に囲まれて暮らす現代において、中高生が「アルゴリズム・ナビゲーター」となり、家族がフィルターバブルやエコーチェンバーに陥るのを防ぎ、多様で良質な情報に触れられるようガイドするAIエージェントです。デジタルネイティブな感性とAIの分析力を組み合わせ、家族の「情報の健康（インフォメーション・ヘルス）」をプロデュースします。

## 主な機能
- **アルゴリズム・オーディット（監査）**: 家族が普段目にしている情報の傾向をAIが分析。特定の偏り（フィルターバブル）がないか、中高生が「情報の健康診断」として報告します。
- **インフォメーション・ダイエタリー・プラン（情報献立）**: 「今週はあえて自分たちの興味の外にあるニュースを見てみよう」など、AIが提案する多様な視点（対立意見や異文化の視点）を中高生がキュレーションして家族に提案します。
- **ラビットホール・アラート**: 家族の誰かが過激な情報や不確かな情報に引き込まれそうになった際、AIがその予兆を検知し、中高生が優しく注意を促したり、客観的なファクトチェック情報を共有したりします。
- **アルゴリズム・トレーニング**: 「どうすれば自分のフィードを好きなもので埋め尽くすか（または多様にするか）」というハック術を、中高生がAIと一緒に家族へレクチャーします。

## ロードマップ
- **v1.0**: 家族の利用傾向の簡易分析と、週替わりの「異視点ニュース」提案機能。
- **v2.0**: 主要なSNS/動画サイトのレコメンド傾向の可視化と、ファクトチェック連携機能。
- **v3.0**: AIによる「情報の栄養価」自動ラベリング機能と、家族間での「良質な情報のシェア」プラットフォーム。
