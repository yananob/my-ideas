# AI中高生『わが家のウェルビーイング・コーチ』 (AI Teen Family Wellness Coach)

## 概要
多忙な現代の家族の心と体の健康を、中高生が「ウェルビーイング・コーチ」となってリードし、AIがそれを強力にバックアップするアプリです。睡眠、食事、運動、そして心のケアを、最新のウェルネス理論とAIのデータ分析に基づいて家族全員で楽しく最適化します。中高生は家族の健康を守る「専門家」としての役割を担い、主体性と科学的思考を養います。

## 主な機能
- **ファミリー・ウェルネス・ダッシュボード**: ウェアラブルデバイスや自己申告データに基づき、家族全員の睡眠の質、活動量、ストレスレベルをAIが可視化。中高生のコーチがこれを確認し、「明日はみんなで早めに寝よう」といった提案を行います。
- **AI栄養・サプリ・アドバイザー**: 家族の体調や目標（「集中力を高めたい」「疲れを取りたい」など）に合わせ、AIが最適な食材や献立を提案。コーチはそれをもとに、週末の買い物リストを作成したり、夕食のメニューをプロデュースします。
- **マインドフルネス・セッション・リード**: AIがガイドする瞑想やストレッチ、呼吸法のセッションを、コーチが家族を誘って実施します。家族でリラックスする時間をデザインし、心理的安全性を高めます。
- **ポジティブ・フィードバック・サポーター**: AIが家族の「良い変化（歩数が増えた、早く寝たなど）」をコーチに通知。コーチが家族に「今日はいっぱい歩いたね！」「早起きできててすごい！」といったポジティブな言葉をかけるきっかけを作ります。

## ロードマップ
- **v1.0**: 睡眠と歩数のデータ同期機能、家族向けの健康状態サマリー表示。
- **v2.0**: 体調に合わせた食材提案機能と、コーチ向けの「声かけアドバイス」機能の実装。
- **v3.0**: AIガイド付きマインドフルネス・プログラムの搭載と、家族の幸福度（ウェルビーイング）の推移を可視化するレポート機能。
