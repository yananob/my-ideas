# AI中高生『わが家の「リスキリング・バディ」』 (AI Teen Family Reskilling Buddy)

## 概要
最新の学習ツールやAIの活用に長けた中高生が「リスキリング・バディ（学習相棒）」となり、親の学び直しやスキルアップをAIと共にサポートするアプリ。親が新しい技術や知識を習得する際のハードルを下げ、親子で共に学び成長する文化を家庭内に築きます。

## 主な機能
- **リスキリング・ロードマップ・デザイナー**: 親が学びたいこと（例：新しい業務スキル、プログラミング、デザイン、言語など）に対し、AIが最適な学習ステップを提案。中高生が「今の時代に合った効率的なツールや教材」をバディとして選定し、ロードマップを完成させます。
- **AIペア・ラーニング・ガイド**: 親が学習中に突き当たった疑問に対し、中高生がAIを使って分かりやすく解説。中高生は「教える」ことで自身の理解を深め、親は「子に教わる」ことで心理的障壁を下げて楽しく学べます。
- **モチベーション・マイクロナッジ**: 学習の進捗をAIが管理。中高生が「今日はここまでやったんだね、すごい！」「明日はこの動画を一緒に見よう」といった応援メッセージ（ナッジ）を送ることで、親の継続を支えます。
- **スキル・デモンストレーション・デイ**: 学んだ成果を家族に披露するミニ発表会をプロデュース。AIが発表資料の作成をサポートし、家族からのフィードバックを通じて、親の学びを実社会や家庭生活に繋げます。

## 家族にとってのメリット
- **親のキャリア・自信の向上**: 最新スキルの習得により、親のキャリア不安が解消され、自己肯定感が高まります。
- **親子の新しい信頼関係**: 「教える・教わる」の関係が逆転したり対等になったりすることで、互いを一人の「学習者」として尊敬し合える関係が築かれます。
- **家庭内の学習文化**: 親が学ぶ姿を子が応援する環境が、子自身の学習意欲や自律性にもポジティブな影響を与えます。

## ロードマップ
- **v1.0**: 学習目標設定ヒアリングと、AIによる推奨教材リスト作成機能。
- **v2.0**: 学習進捗の共有と、中高生からの「応援コメント」送付機能の実装。
- **v3.0**: AIによる「親の苦手ポイント」の特定と、中高生が解説するための「ティーチング・テンプレート」提供機能。
