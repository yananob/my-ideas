# AI中高生『おでかけ自立』サポーター (AI Teen Outing Independence Supporter)

## 概要
中高生になると、友達同士で遠出をしたり、イベントに参加したりする機会が増えます。一方で、親にとっては「どこで誰と何をするのか」「トラブルに巻き込まれないか」という不安がつきものです。このアプリは、中高生が自ら「安全で無理のない計画」を立てるのをAIがサポートし、その内容を親に分かりやすく共有することで、親の安心と子の自立（おでかけの自由）を両立させるエージェントです。

## 主な機能
- **プランニング・ワークショップ**: 行き先、交通手段、予算、帰宅時間などをAIと対話しながら入力。AIが「そのルートだと乗り換えがギリギリかも」「予算が少し足りないかもしれないよ」とアドバイスし、実現可能な計画作りを助けます。
- **安心プレゼン・メーカー**: 立てた計画を、親が気にするポイント（連絡手段、同行者、緊急時の対応など）を網羅した「プレゼン資料」として自動生成。「ちゃんと考えている」ことを親に示し、許可を得やすくします。
- **リアルタイム・チェックイン・バディ**: おでかけ当日、予定の場所への到着や移動のタイミングでAIが本人に「親御さんにスタンプ送る？」と優しく促します。過度な監視ではなく、本人主導の「安心の共有」をサポートします。
- **「信頼の貯金箱」**: 約束通りの帰宅やこまめな連絡を「信頼ポイント」として蓄積。ポイントが貯まると、次回の門限延長の交渉がしやすくなるなど、自律的な行動をポジティブに評価します。

## ロードマップ
- **v1.0**: AIとの対話によるおでかけ計画作成機能と、親への共有用レポート生成機能。
- **v2.0**: 当日の位置情報リマインドと、ワンタップで親に状況を知らせるクイック・チェックイン機能。
- **v3.0**: 過去の行動実績に基づいた「信頼スコア」の可視化と、親子間での「おでかけルール」カスタマイズ機能。
