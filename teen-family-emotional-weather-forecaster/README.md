# AI中高生『わが家の「心の天気」予報士』 (AI Teen Family "Emotional Weather" Forecaster)

## 概要
家族一人ひとりの感情の状態や、家庭内全体の「空気感」をAIが分析し、中高生が「心の天気予報士」となって、心地よい家庭環境をプロデュースするアプリ。ウェアラブルデバイスからのバイオメトリクス解析、音声のトーン分析、さらには最新の感情科学と環境心理学を組み合わせ、ストレスによる「負の連鎖」を未然に防ぎます。中高生は客観的なデータに基づき、家族の絆を深める「快晴」の時間を科学的に最大化するリーダーシップを発揮します。

## 主な機能
- **バイオ・エモーショナル・ダッシュボード**: 家族のウェアラブルデバイス（心拍変動、睡眠の質）や会話のトーン、カレンダー予定を統合。AIが「自律神経の状態」まで踏み込んでわが家の「感情の天気図」を生成し、中高生がリアルタイムで状況を把握します。
- **予測型アトモスフィア・シミュレーター**: 過去のデータと外部要因（仕事の繁忙期、試験、気圧変化、季節行事）を掛け合わせ、数日後の「心の荒天（衝突リスク）」を予測。「水曜日はパパも私も忙しいから、夕食はデリバリーで楽にしよう」といった先回りの提案を中高生が行います。
- **「感情の伝染」ディフェンス・ガイド**: 誰かの不機嫌がどう家族全体に波及しているか（感情の伝染）をAIが可視化。負のループを断ち切るために、中高生に「今、あえてこの冗談を」「リビングの照明を暖色系に」といった具体的な介入アクションをナッジします。
- **マルチモーダル空間演出・プロデュース**: スマートホーム（照明、音響、アロマ、デジタルアート）とフル連携。AIが検知した「天気」に基づき、リビングを「深いリラックスモード」や「集中モード」に自動最適化。中高生はシーンに合わせた独自の空間プリセットをデザインできます。
- **AI共感リペア（修復）コーチ**: 衝突（嵐）が発生した際、AIが「今、相手が感じている本当のニーズ」を推測。中高生が「良き仲裁者」として振る舞えるよう、共感に基づいた対話スクリプトや、わだかまりを解くためのパーソナライズされた「仲直りギフト/クエスト」を提案します。

## 家族にとってのメリット
- **ストレスの先回り管理**: 感情が爆発する前の「予兆」を捉えることで、無意味な衝突が激減し、家庭内が穏やかな場所に変わります。
- **心理的安全性の数値化**: 家族のオープンな対話や感謝の頻度を「心理的安全性スコア」として可視化。良くなっている実感がさらなる良い変化を生みます。
- **科学的な環境作り**: 最新の環境心理学に基づき、光・音・香りを最適化することで、家庭が単なる住居ではなく「心身を回復（リカバリー）させる場所」へと進化します。

## ロードマップ
- **v1.0**: ウェアラブル同期（心拍・睡眠）と、ビジュアル天気図の生成機能。
- **v2.0**: 音声トーンによるリアルタイム感情解析（エッジ処理によるプライバシー配慮型）と、空間演出プリセットの作成。
- **v3.0**: 過去の全データに基づく「月間・心の予報カレンダー」の発行と、スマートホーム（IoT）自動制御の高度化。
- **v4.0**: 感情共鳴（伝染）の因果関係分析と、心理学の専門家監修による「高度な関係性修復プロトコル」の実装。
