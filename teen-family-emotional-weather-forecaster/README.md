# AI中高生『わが家の「心の天気」予報士』 (AI Teen Family "Emotional Weather" Forecaster)

## 概要
家族一人ひとりの感情の状態や、家庭内全体の「空気感」をAIが分析し、中高生が「心の天気予報士」となって、心地よい家庭環境をプロデュースするアプリ。思春期特有の繊細な感性とAIの客観的な分析を組み合わせ、衝突を未然に防いだり、家族の絆を深める「快晴」の時間を増やしたりすることを目指します。

## 主な機能
- **ファミリー・ウェザー・レポート**: 家族の会話のトーンや活動量、簡単なチェックインデータに基づき、わが家の「感情の天気図」をAIが生成。中高生が「今はみんな少しお疲れ気味（曇り）」といった状況を共有します。
- **「不快指数」アラート**: ストレスレベルの高まりや、言葉のトーンの刺々しさをAIが検知。衝突が起きそうな「嵐の予報」を中高生に伝え、適切な距離感やクールダウンを促すナッジを提案します。
- **アトモスフィア・ケア・アクション**: 「空気が重い時」には、AIがおすすめの音楽、アロマ、または「あえてそっとしておく」などのアクションを提案。中高生が指揮を執り、家庭の雰囲気を好転させます。
- **マイクロ・ハピネス・ログ**: 家族の笑顔や、さりげない感謝の言葉など、日常の「小さな晴れ間」をAIが記録。週末に「今週のベスト快晴シーン」として振り返ることで、ポジティブな循環を生み出します。

## 家族にとってのメリット
- **感情の可視化**: 言葉にしにくい「今の気分」を天気として共有することで、お互いを思いやるきっかけが生まれます。
- **衝突の回避**: 感情が高ぶっている人をAIが察知し、中高生がさりげなくフォローすることで、不要な言い争いを減らせます。
- **心理的安全性の向上**: 家族全員が自分の感情を尊重されていると感じ、家がよりリラックスできる空間になります。

## ロードマップ
- **v1.0**: 感情データの簡易入力と、視覚的な「天気図」表示機能。
- **v2.0**: 音声や表情からのリアルタイム感情分析（プライバシー配慮型）と、改善アクション提案機能。
- **v3.0**: 過去の傾向に基づく「週刊・心の天気予報」の発行と、家族のウェルビーイング向上に特化した高度なファシリテーション支援。
