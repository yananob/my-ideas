# AI中高生『わが家の「心の天気」予報士』 (AI Teen Family "Emotional Weather" Forecaster)

## 概要
家族一人ひとりの感情の状態や、家庭内全体の「空気感」をAIが分析し、中高生が「心の天気予報士」となって、心地よい家庭環境をプロデュースするアプリ。思春期特有の繊細な感性とAIの客観的な分析、さらには最新の感情科学（感情の伝染や予測モデリング）を組み合わせ、衝突を未然に防ぎ、家族の絆を深める「快晴」の時間を最大化することを目指します。

## 主な機能
- **ファミリー・ウェザー・レポート**: 家族の会話のトーン、活動量、カレンダー予定、および簡単なチェックインデータに基づき、わが家の「感情の天気図」をAIが生成。中高生が「今はみんな少しお疲れ気味（曇り）」といった状況をリアルタイムで共有します。
- **予測型アトモスフィア・モデリング**: 過去のデータとカレンダー（試験期間、仕事の繁忙期など）を照らし合わせ、数日後の「心の荒天」を予測。「週末はみんなストレスが溜まりそうだから、土曜はのんびり過ごそう」といった先回りの提案を行います。
- **感情共鳴（エモーショナル・レゾナンス）アナライザー**: 一人の不機嫌がどう家族全体に波及しているか（感情の伝染）をAIが分析。「お父さんの仕事の疲れが、お母さんのイライラに繋がっているかも」といった負のループを可視化し、中高生が適切なタイミングで「空気」を切り替えるアクションを促します。
- **マルチモーダル空間演出プロデュース**: スマートホーム（照明、音楽、デジタルアート、香り）と連携。AIが予測した「天気」や中高生のディレクションに基づき、リビングの環境を自動またはワンタップで最適化し、心理的安全性の高い空間を演出します。
- **エモーショナル・リペア・ガイド**: 衝突（嵐）が起きてしまった後、AIが「修復（リペア）」のプロセスをサポート。相手の状態に合わせた謝罪のタイミングや、わだかまりを解くための「仲直りクエスト」を中高生に提案します。

## 家族にとってのメリット
- **感情の可視化と予測**: 言葉にしにくい「今の気分」だけでなく「未来の空気」も共有することで、お互いを思いやる余裕が生まれます。
- **感情の伝染のコントロール**: 誰かの不機嫌に引きずられるのではなく、客観的に状況を捉え、家族全員で良い雰囲気を守る姿勢が育まれます。
- **科学的な空間作り**: 最新の環境心理学に基づいた空間演出により、家庭が真にリラックスでき、エネルギーを充填できる場所になります。

## ロードマップ
- **v1.0**: 感情データの簡易入力と、視覚的な「天気図」表示機能。
- **v2.0**: 音声や表情からのリアルタイム感情分析（プライバシー配慮型）と、改善アクション提案機能。
- **v3.0**: 過去の傾向とカレンダーに基づく「週間・心の天気予報」の発行と、基本的なスマートホーム連携。
- **v4.0**: 感情共鳴分析による負の連鎖の断ち切り支援と、AIガイドによる高度な「関係性修復（リペア）」プロトコルの実装。
